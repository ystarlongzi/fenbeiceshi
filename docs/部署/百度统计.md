# 百度统计

更新：2026-10-27。仅用于 `https://fenbeiceshi.com/` 的简体和 `/zh-tw/` 繁体页面，公开站点 ID 为 `dd4dc5db781946002c436e7f06507c56`。不需要新增环境变量、Secret 或 npm 包；代码与静态产物仍须发布后才在正式站生效。

## 加载与访客选择

实现位于 `src/features/site-analytics/baidu.ts`，由已有统计组件在水合、偏好读取完成且统计开启后加载。脚本地址为 `https://hm.baidu.com/hm.js?dd4dc5db781946002c436e7f06507c56`，设置 `async`，同一文档只插入一次。运行时仅接受 HTTPS 的精确主机 `fenbeiceshi.com`，不接受子域、自定义端口、国际站或本地预览。

百度与 Google 共用原有 `fenbeiceshi:analytics-consent:v1` 偏好。无选择时默认开启；已保存拒绝、尚未完成偏好读取、读取失败且未显式允许时保持关闭。中文站没有 GA4 衡量 ID 时仍保留百度与统计设置。`NEXT_PUBLIC_GA_SHOW_NOTICE` 继续只控制浮动提示，默认隐藏；隐私页可随时允许或拒绝两项统计。

拒绝时调用 `_setAutoTracking` 关闭后续采集，并清理本站可写的此站点 `Hm_lvt_*`、`Hm_lpvt_*`、`Hm_cv_*`、`Hm_ck_*` Cookie；不触碰报告、录音或其他偏好，也无法清除百度域的 Cookie 或已发送的数据。脚本尚未下载完成时撤回，会丢弃本页待发队列中的页面事件。重新允许可恢复，不重复下载脚本。

## 页面与采集范围

关闭 `_setAutoPageview`，改由 `_trackPageview` 发送首屏、站内路径切换与前进后退；同一连续路径去重。传入的页面参数仅为以 `/` 开头的 pathname，不包含查询和锚点。关闭 `_setAutoEventTracking`，不配置自动点击、表单或测量事件，不向统计队列传入音频、读数、备注和测量设备标识。百度脚本仍会处理其基础访问、来源及浏览器／设备信息；不能将本站页面参数过滤描述为对第三方脚本所有网络字段的审计。

简繁隐私正文与统计设置已说明百度及共用开关，国际站正文和 Google 接入保持原范围。脚本加载错误通过 `data-baidu-analytics-load="unavailable"` 与控制台警告保留状态，测量和本机记录可继续使用。

## 依赖选择与维护

| 方案                       | 判断                                                          |
| -------------------------- | ------------------------------------------------------------- |
| 沿用现有 Google 统计       | 无法向用户指定的百度站点收数。                                |
| 百度官方脚本与已有统计组件 | 采用；直接使用指定 ID，复用访客偏好和页面切换，不新增包依赖。 |
| 新增第三方统计封装包       | 增加间接依赖，当前无需采用。                                  |

在线脚本由百度更新，遵循百度服务条款，未取得固定版本或独立开源许可证，不将其视作已通过漏洞审计的 npm 包。异步下载不阻塞 HTML 解析；本轮未测量下载体积或运行耗时。更换 ID、扩大域名、调整后台自动采集或新增事件时，应重新核对采集范围、隐私说明和撤回行为。

技术依据：[百度 JS API 部署说明](https://tongji.baidu.com/holmes/Tongji/统计开放手册/JS%20API部署说明/代码部署)、[页面访问与单页应用](https://tongji.baidu.com/web/help/article?id=235&type=0)、[关闭数据采集](https://tongji.baidu.com/web/help/article?id=363&type=0)、[关闭自动点击采集](https://tongji.baidu.com/holmes/Analytics/技术接入指南/JS%20API/JS%20API%20使用手册)。关闭采集命令使用 `['_setAutoTracking', false]` 的数组参数形式，布尔值与命令处于同一数组。
