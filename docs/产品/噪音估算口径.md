# 噪音估算口径与输入信号

更新：2026-10-22。默认提供估算噪音分贝，按用户确认改为可选的即时读数修正，覆盖原参考读数／点击应用的交互。本文件替代 V2/V3 中“默认 dBFS，校准后才估算”的旧决定；早期截图与验证记录保留其当时语境。

## 结果与辅助信息

- 主仪表、数字、条形、色带、趋势、最低/最高/平均和新记录均显示同一份估算噪音读数。未开启修正时标注“通用估算 · 未修正”；开启后显示实际生效值，例如“手动修正 · +5.0 dB”，零修正为“手动修正 · 0.0 dB”，负数为“手动修正 · −5.0 dB”。记录与报告共用该标签，历史参考记录保留原标注；单位保持“dB · 估算”，辅助说明继续明确手动修正不是专业校准或 dBA。
- 输入信号位于麦克风选择旁，以五根小信号柱反馈原始输入幅度，以文字区分未采集、等待授权、采集中、过载与演示。不会由低信号推断设备故障或环境安静，也不把信号柱当作噪音级别。
- 读数修正默认关闭，不阻挡开始测量。开始前保留破折号；演示显著标记且不能保存或导出为测量记录。停止后信号柱熄灭，噪音结果仍保留。
- 主刻度为 0–120，位置线性映射。微弱、较安静、日常声、嘈杂、极响是帮助理解量级的界面参考，不是健康或法规分级。刻度不是已经验证的设备量程；超出刻度的数值不偷偷截断。
- 趋势图在有数据时显示自定义的 70 dB 警告线、85 dB 危险线，文字“警告”“危险界限”位于各自虚线右端上方，不另设图例；Y 轴与网格按 0、30、60、90、120 dB 等距排列。这两条线针对本页估算读数提供视觉参照，不是 dBA 健康阈值或法定超标判定；不改变读数、统计或导出。

## 当前通用映射

采集引擎保留原始数字信号，统一转换在 `src/features/sound-meter/readings.ts`：

```text
原始 RMS dBFS = 10 × log10(采样窗口均方能量)
通用估算 dB = 原始 RMS dBFS + 100
模型 ID = generic-rms-v1
```

`+100` 是固定、透明且可复现的产品估算假设，不是参考声压、麦克风灵敏度或通用 dBFS→SPL 换算常数。它没有经过跨设备声学精度验证，不声明误差范围，也不因标注“估算”就获得声学准确度。设备灵敏度、增益、频响与系统处理都可能导致明显偏差。公开方法页 `/knowledge/dbfs-vs-db-spl/` 与关于页说明这一点。

这里保留该模型的参数与版本，便于后续用真实设备和参考仪器验证、修订；更新映射时必须新增模型版本，不得重新解释已经保存的旧结果。单元测试验证公式、转换和数据一致性，不能代替真实设备精度实验。

## 即时读数修正

```text
手动修正估算 dB = 原始 RMS dBFS + 100 + 手动修正值
模型 ID = manual-offset-v1
修正范围 = −50 至 +50 dB，步长 0.1，初始值 0
```

设置中开启“读数修正”后，滑块、数字输入和键盘上下键直接更新值；数字框固定 90px，不显示右侧步进按钮，也不显示额外反馈／重置行，不再填写参考来源或点击应用。每次修改均从通用估算计算，不累加上一次的修正。例如原始 −40 dBFS 默认约 60 dB，+5 显示约 65，−5 显示约 55。输入 0 可保留开关并恢复零修正，关闭开关恢复通用模式。输入为空、非数字、超范围或步长不符时，错误提示就近显示，保留上次有效修正，不向读数传递无效数值。

开始前可预设，运行中立即同步改变仪表、色带、整次统计和已有趋势；原始采样、信号柱和音频不变。演示、授权等待和已结束结果禁用修改；结束后的报告使用当时修正快照，重新测量后可继续调整。桌面侧栏和手机／全屏抽屉共用会话状态。刷新、更换麦克风、重新开始时输入签名不匹配，均恢复默认值；同一页面、同一输入的重新测量可沿用。

有参考声级计时，先输入 0，再按 `参考读数 − 网页估算` 得到修正值。未提供声学参考时不要把安静房间、对照表或其他网页当作标准；手动调数仍是未校准估算，不实现 A 计权或全频段补偿。

历史参考记录继续使用 `参考读数 − 原始 dBFS` 的旧偏移，替换通用 +100，不叠加手动修正。旧记录的参考值、来源、时间和输入保持不变。

## 统一计算与边界

`displayFrame` 在工作台入口投影一次，仪表、色带、趋势和统计消费投影结果。平均值先对采样能量求均值，再转成 dB，最后加上当前偏移；不对已显示的分贝做算术平均。记录页和导出复用同一转换函数。

数字零输入仍使用原始计算下限 −100 dBFS。显示和统计保留 `≤` 标记，JSON 保留输入下限标志；它是计算边界，不是房间实际达到的最低声级。削波提示独立保留。采样窗口统计不称为专业 LAeq 或峰值声压，不声称实现 A 计权、合规或安全判定。

首次收到非零采样之前，全零窗口只反馈输入下限，不进入累计统计和趋势，三个分贝统计项显示等待测量，避免启动缓冲把整次最低值锁在 `≤0.0`。首次非零采样开始统计，之后的全零窗口仍计入最低、最高和能量平均；非零但低于计算下限的窗口也不排除。不设环境安静阈值，不将全零输入解释为房间实际声级。始终未收到非零采样的会话结束时不生成可保存摘要；计时仍从开始采集起算。既有摘要不回算。

## 本机记录兼容

- 存储键继续使用 `fenbeiceshi:records:v1`，避免丢失已经保存的数据；新写入的封装版本为 `3`。读取同时支持封装 `1`、`2` 和 `3`，只读时不改写旧数据。
- 新摘要保留 `estimate: { id: "generic-rms-v1", offset: 100 }`、原始统计与趋势；开启修正时另存 `adjustment: { id: "manual-offset-v1", offset }`。修正必须依附通用模型，不能与历史参考同时存在。
- 缺少估算模型的旧记录保留相对 dBFS 或原有参考口径；不会自动加 100。首次保存或删除才写入版本 3，同时保留其余旧记录内容。损坏或未知版本仍报错并保留原始存储。
- 比较要求输入签名、实际模型与偏移一致。旧相对、新通用、手动修正和历史参考估算之间不混比；手动修正值不同也不能比较；两条同输入、同参考偏移的历史参考记录仍可比较。
- 报告内部摘要格式为 `fenbeiceshi-summary-v3`，包含模式、单位、模型 ID、实际总偏移、独立手动修正值、下限标志与同口径趋势。CSV、Excel、PDF 和文字摘要共用这些字段；内部设备签名仍不导出，无录音内容。
- 版本 1、2 封装不得携带手动修正字段，以免被旧应用忽略。回退到旧应用时，旧解析器会拒绝版本 3 并保留数据；不能让旧代码静默覆盖。回退前可导出需保留的摘要，不通过改回存储版本伪造兼容。
- 修正范围由 ±30 放宽至 ±50 时，公式、`manual-offset-v1` 模型及 v3 封装保持不变，旧边界内的记录继续兼容。旧版窄范围读取器会拒绝包含绝对值超过 30 的修正记录；回退旧版本前须先导出这些报告，不应丢弃或截断修正值。

## 依据与验证入口

- [MDN：getFloatTimeDomainData](https://developer.mozilla.org/en-US/docs/Web/API/AnalyserNode/getFloatTimeDomainData)：确认输入是数字采样，常用幅值范围不能直接视为声压。
- [MDN：getSettings](https://developer.mozilla.org/en-US/docs/Web/API/MediaStreamTrack/getSettings)：核对实际设备与音频处理设置。
- [CDC/NIOSH：特定声级计 App 的验证条件](https://www.cdc.gov/niosh/noise/about/app.html)：其结果属于特定应用与设备，不能转用为本站准确度。
- [设计规格](../../design/noise-estimate-v1/design-spec.json)、[本轮验证](../验证/噪音估算调整验证.md)。
