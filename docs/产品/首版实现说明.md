# 首版实现说明

更新：2026-10-18；执行依据：[竞品分析与设计决策](./竞品分析与设计决策.md)、[整站规划](./整站结构与SEO规划.md) 和根目录设计层级规范。

## 当前任务与视觉判断

- 当前任务与状态：用户进入工具，从等待开始，到观察声音，再结束、解释及保存摘要。
- 核心内容与主操作：运行时主角是读数和趋势，等待时是开始操作；结束后是结果及保存。
- 必要支持：模式、单位、输入来源、校准有效性、有效时长与异常，靠近对应对象呈现。
- 按需细节：设备选择、参考校准、指标解释和故障帮助，保持可找到且控制视觉权重。
- 模块关系：主仪表与右侧设置是主辅关系；统计是同级可比较数据；指南是连续阅读，知识入口是对象集合。
- 主要问题：此前方案仪表观察方式较少；需要补充持续观察模式；模块内部需通过读数面、统计和控件建立层次。
- 调整：支持亮暗切换的站点外壳，深绿仪表面、清晰刻度与分区统计；工具先于内容；手机重排操作；不为每段说明添加卡片。

## 实现边界

首版为 Next.js App Router 静态导出，中文根目录、英文 `/en/`。无账户、数据库、后端音频服务和在线统计；音频仅在浏览器内存中处理。2026-10-20 增加默认关闭的同步录音，结束后本机播放并下载 MP3 / PCM；录音仅暂存当前页，刷新、离开页面或新录音会清除，需及时下载，见 [同步录音说明](./同步录音说明.md)。

仪表提供指针、数显和电平条。样式属于视图状态，不修改测量会话。全屏优先使用原生 Fullscreen API，不支持或请求失败时提供页面内专注模式；退出与键盘操作保留。

默认显示“通用估算 · 未校准”的噪音分贝，采用原始 RMS dBFS +100 的 generic-rms-v1 模型。此偏移是产品假设，没有跨设备声学精度验证；参考校准可选，并替换通用偏移。原始计算仍以满幅样本幅度 1 为参考，下限为 -100 dBFS；输入信号移到麦克风旁的小信号柱。仪表、色带、趋势、统计、记录与导出统一投影，方法与兼容细节见 [噪音估算口径](./噪音估算口径.md)。有效窗口的平均按能量求均值后转回对数，不直接平均 dB；该抽样统计不称为连续积分 LAeq 或专业峰值。

参考校准需要正在使用的真实输入和参考声级计读数；保存参考来源、偏移、时间及输入设置签名。切换输入或设置不匹配时恢复通用估算。单点校准不能保证频响、量程或标准符合性。

演示是显著标记的模拟信号，与真实会话隔离，不允许保存或导出为测量记录。演示停止后可重新选择真实测量。

本机记录只保存摘要、估算模型、口径、条件与必要趋势，采用版本化结构并限制数量；无音频片段。新写入封装为版本 2，旧版相对记录保留原 dBFS，不与新估算混比。JSON 导出不包含浏览器内部设备标识。存储不可用或记录格式损坏时告知用户，不静默覆盖旧数据。

右上角支持亮暗切换，首次跟随系统外观，手动选择后在当前浏览器记忆。外观偏好使用独立键 `fenbeiceshi:theme:v1`，刷新、页面跳转及中英切换后保持；系统变化仅在未明确选择主题时生效。切换只更新主题变量，不重新建立测量会话。存储受限时当前页面仍能切换，并提示无法记忆。

主导航根据当前路径持续标记所在栏目：链接本页使用 `aria-current="page"`，一般知识文章详情将“声音知识”标记为 `aria-current="location"`；分贝对照表有独立一级入口，进入该页时只选中它。首页入口只做精确匹配。选中项使用主题强调文字、底色和底部标记，亮暗主题共用语义变量。手机将品牌/外观/语言与菜单分为两行，保留开始测量、分贝对照表、声音知识和本机记录。路径判断仅放在导航链接的客户端边界，站点外壳和正文继续由服务端渲染。

文章目录随实际阅读位置高亮当前章节，使用主题底色、加粗文字、侧边标记与 `aria-current="location"`。点击、直接打开锚点及历史恢复沿用原生链接行为；普通滚动只更新选中项，不改写 URL 或增加历史记录。桌面保留固定侧栏，手机保留页首换行目录。客户端边界仅接收章节 ID 和本语言标题，正文及全部锚点链接继续输出到静态 HTML；声音筛选改变章节高度时重新判断位置。[验证范围](../验证/文章目录锚点高亮验证.md)。

## 工程职责

- `src/app`：中英路由、静态页面、metadata、sitemap 与 robots。
- `src/features/sound-meter`：信号数学、采集生命周期、状态和仪表视图；频繁数据留在 ref，按可读频率刷新 UI。
- `src/features/calibration`：参考校准条件与纯函数。
- `src/features/records`：本机记录的验证、保存、删除与导出。
- `src/features/decibel-chart`：分贝分段概览与声音查询；仅搜索筛选是客户端子树，参考数据与文章在 `src/lib/content` 维护。
- `src/components`：确实共享的站点外壳、图标、正文和首页内容组件；业务组件独立 kebab-case 目录。
- `src/lib/content`、`routing`、`seo`：类型化内容、真实已完成的双语路由与 SEO 派生数据。
- 样式采用相邻 CSS Modules；globals.css 只维护重置、全局元素和公共变量。原始 V1/V2 设计资产保留，不批量格式化历史资产。

## 首页模块关系调整（V4）

测量与本机记录合为同一工作区域，记录接续测量结果；使用步骤是靠近主任务的紧凑辅助引导。场景区采用较强标题和同级对象表面，知识区用独立阅读背景及导读/文章主辅布局，常见问题回到页面底色并降低标题权重。手机端的步骤、导读和问题按阅读顺序重排。

当前中英文场景区直接展示房间、家电开关与开关窗的两步操作说明，使用静态列表，不再将场景名称链接到通用帮助文章，也不设置额外测量入口。图标与主题表面沿用现有设计，正文保持静态输出；实现及验证见 [首页场景说明调整验证](../验证/首页场景说明调整验证.md)。

这些变化只涉及首页模块组织、文字和相邻 CSS Modules。工作台通过局部 CSS 变量接受外部轮廓，不依赖私有选择器。该段描述当时版本；当前读数、参考校准与记录口径由噪音估算规格覆盖。[设计规格与截图](../../design/home-hierarchy-v4/design-spec.json)，[实际验证](../验证/首页层级调整验证.md)。

主题配色与记忆行为见 [主题 V1](../../design/theme-v1/design-spec.json)，覆盖范围与实际检查见 [亮暗主题验证](../验证/亮暗主题验证.md)。

## 分贝对照联动与健康模块（2026-10-18）

七档概览可选择，并与 0–160 整数数值输入、滑块和声音列表联动。分段交界值归入后一档；参考范围按交集匹配，原有名称、单位和类别筛选继续组合使用，清除与重置均有明确入口。选择分段后定位并聚焦结果计数，数值探索保留输入焦点。共享状态使用局部 Provider，`ContentPage`、健康正文及来源仍由服务端生成，默认 31 项声音继续存在于静态 HTML。

职业暴露演示在既有章节中手动选择 85–100 dBA，按 NIOSH 的 85 dBA／8 小时及 3 dBA 交换关系计算近似参考时长；范围外、空值和非法输入不输出时长。它不读取仪表估算，也不输出个人安全倒计时。六类健康主题位于该章节之后，提供常驻摘要、原生展开、应对建议和逐项一手来源；首页知识区提供简短导读并链接 `#health`。中英文对应内容、目录锚点及来源同步，路由与索引数量不变。

本轮按用户确认范围增加有来源的一般科普，不新增独立健康文章；候选 P2 专文继续按原发布条件维护。来源核对不等于完成医学或声学实测。[V2 规格](../../design/decibel-chart-v2/design-spec.json)，[实际验证](../验证/分贝对照联动与健康模块验证.md)。

## 常见问题、工作原理与标题优化（2026-10-21）

当前首页常见问题从 3 问扩展为 8 问，与 `/faq/` 的六组 17 问共用数据、原生展开和详细帮助链接。新增 `/how-it-works/`，按麦克风采集、声音能量、估算映射、趋势统计四步介绍，并解释设备差异和音频保存。两页均有真实中英文静态正文，当前为 28 个中英 URL，26 个可索引，尚未部署。
