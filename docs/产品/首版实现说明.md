# 首版实现说明

更新：2026-10-17；执行依据：[竞品分析与设计决策](./竞品分析与设计决策.md)、[整站规划](./整站结构与SEO规划.md) 和根目录设计层级规范。

## 当前任务与视觉判断

- 当前任务与状态：用户进入工具，从等待开始，到观察声音，再结束、解释及保存摘要。
- 核心内容与主操作：运行时主角是读数和趋势，等待时是开始操作；结束后是结果及保存。
- 必要支持：模式、单位、输入来源、校准有效性、有效时长与异常，靠近对应对象呈现。
- 按需细节：设备选择、参考校准、指标解释和故障帮助，保持可找到且控制视觉权重。
- 模块关系：主仪表与右侧设置是主辅关系；统计是同级可比较数据；指南是连续阅读，知识入口是对象集合。
- 主要问题：此前方案仪表观察方式较少；需要补充持续观察模式；模块内部需通过读数面、统计和控件建立层次。
- 调整：浅色站点外壳，深绿仪表面、清晰刻度与分区统计；工具先于内容；手机重排操作；不为每段说明添加卡片。

## 实现边界

首版为 Next.js App Router 静态导出，中文根目录、英文 `/en/`。无账户、数据库、后端音频服务和在线统计；音频仅在浏览器内存中处理。

仪表提供指针、数显和电平条。样式属于视图状态，不修改测量会话。全屏优先使用原生 Fullscreen API，不支持或请求失败时提供页面内专注模式；退出与键盘操作保留。

默认读数为相对 RMS dBFS，以满幅样本幅度 1 为参考；显示下限明确记录为 -100 dBFS。有效窗口的平均按能量求均值后转回对数，不直接平均 dB；该抽样统计不称为连续积分 LAeq 或专业峰值。

参考校准需要正在使用的真实输入和参考声级计读数；保存参考来源、偏移、时间及输入设置签名。切换输入或设置不匹配时回到相对模式。单点校准不能保证频响、量程或标准符合性。

演示是显著标记的模拟信号，与真实会话隔离，不允许保存或导出为测量记录。演示停止后可重新选择真实测量。

本机记录只保存摘要、口径、条件与必要趋势，采用版本化结构并限制数量；无音频片段。JSON 导出不包含浏览器内部设备标识。存储不可用或记录格式损坏时告知用户，不静默覆盖旧数据。

## 工程职责

- `src/app`：中英路由、静态页面、metadata、sitemap 与 robots。
- `src/features/sound-meter`：信号数学、采集生命周期、状态和仪表视图；频繁数据留在 ref，按可读频率刷新 UI。
- `src/features/calibration`：参考校准条件与纯函数。
- `src/features/records`：本机记录的验证、保存、删除与导出。
- `src/components`：确实共享的站点外壳、图标、正文和首页内容组件；业务组件独立 kebab-case 目录。
- `src/lib/content`、`routing`、`seo`：类型化内容、真实已完成的双语路由与 SEO 派生数据。
- 样式采用相邻 CSS Modules；globals.css 只维护重置、全局元素和公共变量。原始 V1/V2 设计资产保留，不批量格式化历史资产。
