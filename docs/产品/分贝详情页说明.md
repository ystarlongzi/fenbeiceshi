# 分贝详情页说明

更新：2026-10-22。状态：本地实现，未部署生产。

## 范围与入口

按既有 31 项声音参考的准确单值或完整范围组织 28 个主题，每个主题提供简体、繁体和英文，共新增 84 个 URL。图书馆与冰箱、体育赛事与最大音量耳机、吹风机与雷声各共享相同数值页面，但保留各自来源、原始单位和条件。不把范围取中点，不批量创建每个整数的页面，也不只做早先讨论的几个常见整数。

入口位于每个声音展开后的描述段落中，文字为“了解 ×× 分贝”（三语对应），接在比较条件说明之后，随文字自然换行；声音展开说明不显示来源机构、资料出处或来源入口，完整引用在详情页查看。七档声音列表默认折叠，点击分组显示标签，再点击标签查看描述与行内入口；搜索继续自动展开匹配分组，清空恢复折叠。

## 内容与层级

当前层级以 [分贝详情 V3](../../design/decibel-details-v3/design-spec.json) 为准：短 H1 后先给参考声级、浏览档位和直观结论，再安排声音场景、量级对比、听力风险、常见问题、来源及延伸阅读。手机先读到结论，再查看目录。

声音场景采用主题表面与分隔列表，保留原单位、完整范围、条件和来源。量级对比改为同一声音降低 10／3 分贝、保持原声级、提高 3／10 分贝的五行三列表格，突出本页参考，并列出近似听感和声音能量。40 分贝页展示 30、37、40、43、50；范围页同时改变两端，不取中点。表格只演示相同测法及单位下的音量变化，不把不同声音场景或 dB 与 dBA 互相换算，也不据此增加整数路由。

听感与能量统一显示数字倍数，如 `×0.81`、`×1.2` 和 `×0.5`、`×2`，使用两位有效数字的近似值。非当前行的声级若与已有详情的单值或完整范围完全一致，则提供当前语言的原生链接；仅落在某个范围内的数字不匹配该范围页。表格上方用独立的主题色提示块、加粗文字与左侧强调线突出“多 10 分贝的听感”和“多 3 分贝的声音能量”两条提醒。

听力标题直接使用“×× dB 对听力有害吗？”，先按低声级、较响范围、强声及烟花突发声回答，再给出降低音量、距离或休息建议，不提供个人安全时长。常见问题每页有两条单独编写的生活化问答，再回答“手机测出来不一样，正常吗？”；先回答问题，再补充必要条件，避免以“口径、计权、统计指标”等术语开头。听力说明之后直接进入常见问题，问答继续使用三级标题。

分贝对照表是父页，正文面包屑与 BreadcrumbList 均显示“首页 → 声音知识 → 分贝对照表 → 当前详情”。父页 31 项描述提供可抓取原生链接，详情连接父页、相关声音与既有指南。三语逐项编写，不依赖运行时文字转换。

## 来源与解释

沿用 [声音参考来源逐项核验](../验证/声音参考来源逐项核验.md) 的 31 项原始数字、单位和条件；新页面没有新增声级例子。WHO、NIDCD、CDC、NPS、NIOSH 与 CCOHS 官方网页及可读取 PDF 已复核。EPA 原文链接本次抓取不可达，沿用已有逐项核验记录，不声称本轮重新读取成功。

EPA 1979 年住宅、餐厅及交通例子继续标明历史资料；1986 年 CDC/NIOSH 馆藏家电表格保留 0.9 米测距；手电钻与链锯保留图示参考的条件限制。100 页的吹风机为 dB、雷声为 dBA，不能因同数字共页而互换单位。NIOSH 85 dBA／8 小时只作为职业时间平均参考，不能从声音示例或网页估算推算个人安全时长。

## 实现与 SEO

- 内容：src/lib/content/decibel-details/ 按声音主题分文件，汇总为现有 SiteContent。
- 展示：src/features/decibel-details/ 使用服务端组件及相邻 CSS Modules；声音详情数据不进入搜索客户端，只传所需链接地址与文案。
- 注册：沿用 src/lib/routing/pages.ts 与现有动态静态路由，不新增依赖。
- SEO：每页独立标题、摘要、自 canonical、互返 hreflang、BreadcrumbList 和站点地图。全站共 126 个三语 URL，其中 123 个可索引，三个记录页继续 noindex。
- 关键词归属：对照表承接总览与查询；28 个详情主题承接各自单值／完整范围及声音问题。候选词没有经验证的搜索量、排名或难度数据。

实际验证见 [分贝详情与行内链接验证](../验证/分贝详情与行内链接验证.md)，当前量级对比与文案见 [V3 验证](../验证/分贝详情量级对比与通俗文案验证.md)；[V2 层级验证](../验证/分贝详情层级与内容结构验证.md) 与 [V1](../../design/decibel-details-v1/design-spec.json) 保留为历史记录。
