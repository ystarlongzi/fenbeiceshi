# 国际站多语言扩展

核对日期：2026-10-25。当前产品继续共用同一套测量、录音和本机记录能力；简体与繁体保留在 fenbeiceshi.com，新增语种位于 soundmetergo.com。语言支持按真实翻译内容发布，不用语言菜单数量代替内容完成度。

来源为两站首页公开的 hreflang 与语言入口，并逐个请求对应首页核对状态和 html lang。这里核实的是语言首页可访问性，不代表逐篇审校过竞品翻译，也不采用竞品对测量准确性或健康风险的声明。原始核对结果保存在本机 artifacts/multilingual-research/。

按语种合并后覆盖 27 种显示版本：现有简体、繁体和英文，加 24 种新语言。两站葡语分别标为 pt-br 和 pt；本轮统一采用巴西葡语 pt-BR、路径 /pt-br/，不为近似内容同时创建两个葡语规范页。挪威语采用 /no/，文案使用 Bokmål。

## 内容与工程边界

- 英文继续使用 soundmetergo.com 根路径；新增语言使用各自固定前缀。中国大陆法规的翻译继续明确原法域，不改写为目的语言国家的法规。
- 界面、测量状态、权限错误、录音、记录、报告和实际发布页面分别纳入翻译清单；备注、设备名称、音频、数字与来源机构原名不参与自动转换。
- 每个已发布页面自 canonical，只有真实对应的语言页互返 hreflang；未完成翻译的页面不生成占位 URL。
- 词典按当前语言加载；客户端仅接收当前语种需要的界面文案，文章正文保留静态 HTML，不把全部语种正文打入工具脚本。
- 阿拉伯语需要 RTL 排版；仪表、趋势、时间轴、单位和数学关系保持明确的读取方向。语言菜单要支持长列表滚动、键盘定位和移动端触达，沿用固定字号。
- 新语言共用 soundmetergo.com 的浏览器存储，保留已有报告格式与录音，不按语言复制或清空数据；中文域与国际域的来源隔离继续生效。

## 实施状态

本轮覆盖现有 47 个主题，包含工具、记录、指南、FAQ、知识正文与 28 个声音详情主题。每个新语种有 1422 条文案，按界面、知识正文和声音详情分别存放在 src/lib/i18n/messages/；现有三语正文继续作为源文案。合计 1269 个 URL，中文域 94 个、国际域 1175 个，其中 27 个记录页 noindex，sitemap 合计 1242 个 URL。

初稿使用经过线上公开性匹配的英文文本离线翻译，再补写参数模板、迁移说明和缺失项，润色首页搜索标题、描述及部分术语，复核数值、单位和机构名。未进行 24 种语言全文的母语审校，不填写虚构审稿信息；搜索词是对应主题的候选表达，没有新增搜索量或排名结论。运行及构建只读取仓库内词典，不调用翻译服务。

2026-10-26 继续对 24 种新增语言的全站标题、描述、主要按钮、测量提示及 17 组 FAQ 做逐语言编辑核对，修正仪表、实时状态、报告、录音、声音场景和数学关系的误译，并增加 FAQ 操作名称与控件一致性检查。具体修改与验证见 [国际站多语言文案精校验证](../验证/国际站多语言文案精校验证.md)；本轮范围不等同于长篇文章全文的母语审校。

src/lib/i18n/load-messages.ts 仅供服务端按语言加载；客户端边界接收当前语种界面词典。缓存以语言为键保存不可变文案，不保存请求语言或用户数据。缺少翻译会阻断检查和构建。动态数值及标签使用具名参数，在翻译后插入；备注、设备名称及录音不会送去翻译。维护现有英文、简体或繁体文案后运行 npm run test:content，源文案变化会提示需要同步的词典键。

路由采用各语种固定目录，复用 src/lib/i18n/routes.tsx，避免动态单段目录抢占 /guide 等原有路径。Next.js 静态导出不接受空参数列表，两次构建均生成真实内容；打包前国际输出移除繁体目录，中文输出移除 24 个国际语言目录。阿拉伯语正文、表格和报告支持 RTL，数值输入、仪表刻度及趋势时间轴保持 LTR。

本地完整检查和桌面／手机浏览器验证已完成，实际范围见 [国际站多语言支持验证](../验证/国际站多语言支持验证.md)。生产状态以发布工作流和两域版本标记为准，不能将语言登记或生成翻译稿等同于已经上线。
