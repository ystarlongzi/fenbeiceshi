# 同步录音说明

更新：2026-10-20。功能为浏览器本机录音，没有音频上传、服务器转码或云端存储。

## 使用与状态

“同步录音”默认关闭，不保存开启偏好。开始真实测量前勾选，与仪表共用同一条麦克风流和 AudioContext。运行、等待授权和演示中锁定开关，演示不录音。录音启动失败会就近提示，测量仍可运行。

结束测量、页面离开前台或输入中断时立即停止麦克风，等待处理器回传尾部采样后关闭共用上下文。不能回传时最多等待 1.5 秒，保留已取得的片段并提示中断，不把不完整录音描述为完整录音。授权等待或模块加载期间取消，不会在稍后恢复录音。

为约束内存，单次录音最多 10 分钟，PCM 采样最多 64 MiB；高采样率时可能先达到内存上限。达到上限只停止录音，测量继续，并显示已保留片段的说明。

结束后通过浏览器音频控件播放；PCM 可直接下载，MP3 首次点击时在本机 Worker 编码，完成后显示下载入口。编码器失败或超时时保留 PCM，可重试。播放使用带 WAV 头的同一份 PCM；不是把其他编码的文件改后缀。

## 格式与保存

- PCM：单声道、有符号 16 位、小端、无文件头的 `.pcm`，采样率来自实际 AudioContext；界面和文件名标明采样率，导入音频软件时需设置这些参数。
- MP3：LAME 编码，目标 128 kbps、单声道；输入来自同一份 PCM，编码器可根据采样率选择合法输出参数。
- 播放与下载仅使用 Blob / Object URL，不使用网络上传。录音不进入 localStorage、JSON、历史摘要或设备比较。
- 当前页只保留最新一段。刷新、离开页面、成功开始新录音或清除录音会释放页面中的音频；关闭同步录音后的普通测量不删除上一段。新录音启动失败时保留上一段。
- 下载文件由用户设备保存，清除页面录音或网站数据不会删除已下载文件。音频下载按钮与摘要保存、JSON 导出分开。

## 目录与实现

`src/features/audio-recording/` 管理录音生命周期、PCM/WAV、MP3 Worker、录音选项及结果，各组件样式相邻。`public/audio/pcm-recorder.js` 在 AudioWorklet 线程转换并分块传回单声道 PCM，输出静音，避免麦克风回授。`CaptureSession` 只增加可选的采集分支，默认关闭时不加载录音处理器。原有音量算法、校准和摘要结构保持原定义。

`public/vendor/lamejs/` 保留独立、未修改的编码器、完整许可证、固定提交源码与替换说明。Worker 只在用户生成 MP3 时从本站加载该模块。隐私页和录音结果提供许可证入口。

## 验证入口与边界

沿用 `npm run check`。新增测试覆盖工作线程真实 PCM 字节、尾部 flush、限额、取消与资源释放，使用实际编码器核对 MP3 内容；桌面和手机视口验证中英操作布局。执行结果、浏览器范围和实机边界见 [同步录音验证](../验证/同步录音验证.md)。
