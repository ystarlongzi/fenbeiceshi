# 同步录音说明

更新：2026-10-21。功能为浏览器本机录音，没有音频上传、服务器转码或云端存储。

## 使用与状态

“同步录音”默认关闭，不保存开启偏好。开始真实测量前勾选，与仪表共用同一条麦克风流和 AudioContext。运行、等待授权和演示中锁定开关，演示不录音。录音启动失败会就近提示，测量仍可运行。

结束测量、页面离开前台或输入中断时立即停止麦克风，等待处理器回传尾部采样后关闭共用上下文。不能回传时最多等待 1.5 秒，保留已取得的片段并提示中断，不把不完整录音描述为完整录音。授权等待或模块加载期间取消，不会在稍后恢复录音。

为约束内存，单次录音最多 10 分钟，PCM 采样最多 64 MiB；高采样率时可能先达到内存上限。达到上限只停止录音，测量继续，并显示已保留片段的说明。

结束后通过浏览器音频控件播放。点击“导出数据”打开报告弹框，有本次录音时显示 MP3、PCM 入口；原录音区也保留下载，达到录音上限而测量继续时仍可使用。PCM 可直接下载，MP3 首次点击时在本机 Worker 编码，完成后显示下载入口。两处共用同一编码任务与文件，关闭弹框不会取消编码；清除录音或成功开始新录音会取消任务并释放文件。编码器失败或超时时保留 PCM，可重试。播放使用带 WAV 头的同一份 PCM；不是把其他编码的文件改后缀。

## 格式与保存

- PCM：单声道、有符号 16 位、小端、无文件头的 `.pcm`，采样率来自实际 AudioContext；界面和文件名标明采样率，导入音频软件时需设置这些参数。
- MP3：LAME 编码，目标 128 kbps、单声道；输入来自同一份 PCM，编码器可根据采样率选择合法输出参数。
- 播放与下载仅使用 Blob / Object URL，不使用网络上传。原始 PCM 可随报告存入 IndexedDB，不进入 localStorage、JSON、数据摘要或设备比较；localStorage 只增加版本化的录音采样参数标记。
- 当前页只保留最新一段。刷新、离开页面、成功开始新录音或清除录音会释放页面中的副本；已存报告的录音不受影响。关闭同步录音后的普通测量不删除上一段，新录音启动失败时也保留上一段。
- 报告与录音通过测量 ID 对应。保存报告时，同次录音默认勾选保存，可取消勾选仅存数据；整理尾部时暂不提供保存按钮，避免漏存。关闭录音后的新测量不会附上上一段音频。历史报告从 IndexedDB 读取同 ID 的 PCM，直接下载 PCM、按需生成 MP3；旧记录无法恢复未保存的音频。记录页备注仅供本次导出，不改写已存内容。
- 下载文件由用户设备保存，清除页面录音或网站数据不会删除已下载文件。MP3、PCM 是独立音频文件，不嵌入 CSV、Excel、PDF 或复制摘要。

## 目录与实现

`src/features/audio-recording/` 管理录音生命周期、PCM/WAV、MP3 Worker、录音选项及结果，各组件样式相邻。`use-audio-clip` 统一管理播放／下载 URL 和可取消的 MP3 任务，工作台与历史读取复用；关闭工作台报告不取消当前页编码，关闭历史弹框会取消其编码并释放 URL。`src/features/records/recording-storage.ts` 管 IndexedDB，`mutations.ts` 管报告与音频的保存、删除和淘汰。`public/audio/pcm-recorder.js` 在 AudioWorklet 转换并分块传回单声道 PCM，输出静音。`CaptureSession` 保留可选采集分支，默认关闭时不加载录音处理器。原有音量、校准、旧摘要版本与比较口径保持原定义。

录音结果区保留标题、时间、时长、采样率、播放、MP3 / PCM 下载及清除操作，不再单列格式说明、许可链接或临时保存提示；编码、限额、中断及播放失败提示仍按状态显示。PCM 参数与保存范围在报告弹框及使用指南说明。

`public/vendor/lamejs/` 保留独立、未修改的编码器、完整许可证、固定提交源码与替换说明。Worker 只在用户生成 MP3 时从本站加载该模块。隐私页提供许可证入口。

## 本机存储、容量与兼容

- 数据库 `fenbeiceshi:recordings:v1`，IndexedDB 版本 1，`clips` 对象仓以 `measurementId` 为主键。每项只保存版本、原始 PCM Blob、实际采样率、帧数、开始时间、限额和中断标记；不重复存 WAV 或 MP3。读取后用同一 Blob 创建 WAV 头，不复制整段 PCM。
- 摘要沿用 `fenbeiceshi:records:v1` 和格式版本 2，新增可选 `recording: {version:1, sampleRate, frames}`。原版本 1／2 记录继续读取，不迁移或重新解释旧值。新增对象仓由 `onupgradeneeded` 创建；不批量修改已有摘要，没有历史音频回填。
- PCM 总量上限 200 MiB，保存前扣除同 ID 将替换的音频及即将淘汰的报告音频，再判断容量。不会单独删除仍保留报告的录音腾空间。浏览器实际配额可能更小，原生配额异常会提示；报告与录音保持原状态，页面副本可继续下载。可取消选存录音，仅保存数据。
- 所有新版本写操作在同一 IndexedDB 读写事务内读取最新摘要、计算容量、更新／删除 Blob；成功后写摘要并通知订阅者。摘要写入失败会中止音频事务；事务后续中止时有条件回退摘要，不覆盖另一页面的新数据。删除、重试、覆盖同 ID 幂等，保存时同步清理不再关联任何报告的音频。
- localStorage 与 IndexedDB 没有共享原子事务：若浏览器在摘要写入后、音频事务完成前崩溃，可能出现摘要带标记但音频缺失，或遗留无关联音频。读取会明确提示缺失且仍允许导出数据；后续写操作清理孤立音频。不能宣称崩溃时跨存储 ACID。
- IndexedDB 不可用时，仅允许不写入或淘汰音频的数据操作；不能假装完成音频保存或删除。升级阻塞／超时会提示，版本切换会关闭连接。历史弹框读取失败可关闭重试，缺失或损坏音频不影响四项数据导出。
- 清除网站数据会删除摘要与录音，浏览器也可能回收站点存储。仅同一浏览器、同一来源可见，不跨设备同步。旧构建不处理音频清理，回滚后勿继续保存／删除带录音记录；恢复新构建后，下一次写操作清理已失去关联的音频。重要录音应先独立下载。

## 验证入口与边界

沿用 `npm run check`。测试覆盖工作线程真实 PCM 字节、尾部 flush、限额、取消与资源释放，使用实际编码器核对 MP3 内容；桌面和手机视口验证中英操作布局。执行结果、浏览器范围和实机边界见 [同步录音验证](../验证/同步录音验证.md)，报告弹框接入及下载验证见 [工作台控制与导出验证](../验证/工作台控制与导出验证.md)。
