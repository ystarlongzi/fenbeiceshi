# Bing 中文页面 SEO 优化优先级

日期：2026-11-23。范围为首页以外的中文页面，以简体为主，繁体单列。前段保留分析时的基线与建议，实际改稿、索引提交和发布状态见末尾执行进展；今天刚上线的首页保持观察，不立即重复调整。

建议顺序：先优化已有流量的简体分贝对照页，同时推进法规页的抓取与收录；再让 30、40、60–70 分贝等既有详情页承接具体问题。其余内容按新曝光继续筛选，暂不整站重写标题。

## 数据来源与适用范围

- [搜索性能](https://www.bing.com/webmasters/searchperf?siteUrl=https://fenbeiceshi.com/)：30 天，2026-10-23 至 2026-11-21，默认全地区、全部设备，关键词及页面数据为 Web 流量。本轮读取了 109 条不同的站点查询、页面列表及简繁对照页的关联查询。该窗口早于本次首页上线，不能用于评价新标题效果。
- [关键词研究](https://www.bing.com/webmasters/keywordresearch?siteUrl=https://fenbeiceshi.com/)：中华人民共和国、中文（简体中文，中国）、全部设备、3 个月；有趋势的本次种子词显示 2026-08-22 至 2026-11-20。无趋势的词只记“数据不足”，不补写零搜索量。共核对 9 个种子词。
- 关键词研究的“印象数”用来观察 Bing 需求，与本站曝光、月搜索量和全网搜索量不同；K 为界面取整显示。两个报告的周期、地区和统计维度不同，不相除推算份额，不相加近义词预测流量。
- 真实页面以当前发布注册及静态导出为准。中文域有 92 个可索引 URL，简繁各 46 个；除去首页，各有 45 个可索引非首页主题。本机记录页继续 noindex。规划 JSON 中的候选路径不当作已发布页面。

## 内容缺口与第一批执行清单

**基础单位解释为研究候选。** 现有 dBFS／dB SPL 文章和工作原理主要解释本站的数字输入与估算，不是面向普通读者的单位入门。`分贝` 5.7K 需求值得研究；本站整体查询 `db` 约 1.7K 曝光、0 点击，存在明显歧义。可以先在现有内容提供通俗解释，再结合规划中的 dB／dBA 主题核对主意图，决定是否需要独立页面。候选 `/knowledge/db-vs-dba/` 当前未发布；不把需求研究记为已实现页面。

第一批建议完成以下事项：

1. **法规抓取。** 保留本轮“索引状态未爬、实时可索引”的基线，核对提交记录和站内入口；需要时通过 Bing 的“请求编制索引”提交重点 URL，并记录结果。不要把提交成功记为收录成功。
2. **对照页的小改动。** 保留现有标题主词、七档结构及 31 项参考，将导读中的 40、50 左右、60–70 等已有答案连到恰当详情。涉及 50 的查询优先由 45–55 范围内容解释。补充声音参考与法规标准的关系说明，并通过现有正文链接到法规页；不新增同款数值页或推荐卡片。
3. **三个详情页的承接。** 先核对 30、40、60–70 页的第一段、父子链接及已有常见问题。40 分贝已有“卧室会不会吵”等 FAQ，复用已有答案，避免重复添加相同章节。60–70 的原始完整范围与 dBA 条件保留。
4. **标准意图。** 法规页收录后重点观察“噪音标准”“噪音扰民标准”和时段问题，再决定是否调整标题与首段。标准名可以进入相应章节和官方引用；厂界排放、环境质量、职业接触分开，不用网页估算判断违法或达标。
5. **设立下一次比较。** 按后续实际发布日记录改动 URL、版本和日期，间隔 2–4 周比较相同地区、设备与 Web 口径的页面及页面关联查询。先看法规页是否抓取／收录、详情是否开始出现曝光，再看相近排名与词组下的点击率。简繁分开，不把总 CTR 的变化直接归因于文案。
