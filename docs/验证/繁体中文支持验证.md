# 繁体中文支持验证

日期：2026-10-21。范围为本地实现与浏览器验证，尚未部署生产。

本记录保留最初的语言链接方案；当前入口已改为显示完整语言名称的下拉框，后续实现与截图见 [语言下拉菜单验证](./语言下拉菜单验证.md)。

## 实现与维护

- 简体中文使用根目录与 `zh-CN`，繁体中文使用 `/zh-tw/` 与 `zh-TW`，英文使用 `/en/` 与 `en`。每种语言 14 个页面，共 42 个 URL；39 个可索引，三个本机记录页保持 noindex。
- `src/lib/i18n/locales.ts` 统一维护语言清单、前缀、语言名称、Open Graph 区域和报告日期格式。`languageHref` 移除完整的语言前缀，切换到当前主题；缺少对应页面时回到目标语言首页。
- `src/lib/i18n/text.ts` 提供显式三语字段和选择函数；文章、问答、七档、31 项声音、职业参考演示、仪表、录音、记录和报告都包含独立繁体文案。`translations` 负责定义多语言文字，`text` 选择内容字段，`localize` 选择简短界面文案。
- 繁体采用「麥克風、瀏覽器、權限、儲存、匯出、校正、指針、全螢幕」等界面用词，并采用繁体字体回退。它是现有内容的对应版本；来源、适用范围、测量单位与模型不因语言改变。
- 新增繁体静态路由，正文继续服务端输出；语言切换仍为局部客户端组件，桌面及手机菜单显示另外两种语言的原生链接。测量与阅读层级沿用现有实现，仅为语言入口增加相邻样式。
- 声音搜索同时索引简体、繁体和英文名称，数字查询接受「分贝」与「分貝」。搜索结果仍按原始单位、范围和七档分组。
- 三语共用原有记录及录音存储，不迁移或翻译用户备注、设备名称和历史数值；报告使用当前界面的字段语言，日期使用相应区域格式。
- canonical 保持每页自引用；hreflang 在三语页面间互相返回并包含自身，x-default 保留简体默认页。sitemap 排除三个记录页。
- 同步 README、AGENTS、SEO 规划、工程参考、关键词映射和文档索引；未实现的候选页面没有新增繁体占位路由。

本轮仅在临时工具目录使用 [OpenCC 1.4.2](https://github.com/BYVoid/OpenCC) 的 `s2twp` 辅助生成初稿，再复核界面术语。项目未加入转换器依赖、词典、网络翻译或运行时 DOM 转换；包清单及锁文件不变。后续文案需显式维护三种语言，不能只改简体后假设繁体会自动更新。

## 实际浏览器验证

使用 Codex 内置浏览器，开发服务为 `http://127.0.0.1:3181`。覆盖默认 1280×720、1141×800 桌面视口，以及 390×844、320×740 手机视口；视口验证不代表真实手机硬件验证。

- 从简体首页进入繁体首页；繁体分贝对照页切至英文，再切回繁体，均保留深层路径。
- 手机菜单展示完整六项导航、主题入口和另外两种语言；导航可关闭菜单，320px 下语言区域可换行。
- 检查繁体首页、设置、知识正文、记录空态与已有记录；1141px 桌面及 390px 健康文章检查无横向溢出。
- 检查繁体健康文章的桌面暗色主题，确认语言和布局正常后恢复亮色与首页；浏览器视口覆盖已重置。
- 对照页输入「洗碗機」得到 1/31 项；输入「60 分貝」得到 5/31 项，保持原始范围与单位。
- 健康演示默认显示「8 小時」；输入 100 得到「15 分鐘」，输入 131 显示繁体范围错误；恢复 85 后保存截图。
- 使用项目既有合成输入夹具，选择繁体，验证待测、运行、结束、录音、保存及报告界面。录制约六秒合成信号，未请求真实麦克风。
- 实际下载 CSV、Excel、PDF，复制繁体摘要，验证 MP3 生成后显示「下載 MP3」。读取 CSV 与 Excel 文件，确认繁体字段、双工作表及混合文字备注 `QA 繁體輸出；原始备注不转换` 原样保留；PDF 检查文件头与结尾，未逐页核对视觉内容。
- 保存合成报告及 PCM 后，繁体记录页显示同一报告、原始设备名与备注，录音标记及估算数值保留。测试数据仅位于该本地端口的浏览器存储，未访问生产域名。
- 临时 `/workbench-qa/` 路由已通过 `node scripts/workbench-fixture.mjs close` 移除，不进入生产构建；实际下载的测试文件移至 `/tmp/noise-i18n-validation/`。

## 验证边界

没有重新验证真实麦克风、真实手机、声学校准、生产服务器、TLS 或 Cloudflare；没有新增地区法规或医学判断。繁体正文已做术语与静态完整性复核，尚无独立母语编辑审校。复制摘要实测成功，复制失败回退没有在本轮浏览器中复现；相关错误文案已补齐。音频、存储和测量算法沿用现有实现，并通过原有测试回归。
