# 首页场景说明调整验证

日期：2026-10-21。范围为本地中文首页 `/` 与英文首页 `/en/` 的三个日常场景说明。

## 任务与实现

原来的房间、家电与关窗场景分别链接到通用使用指南、手机准确性说明和参考校准页，目的页没有直接承接卡片中的观察任务。当前将场景区改为可以直接阅读的操作说明，每项两步，不设置跳转、箭头或额外测量入口。

- 房间：固定设备和位置、测量并保存，换时段复测，记下门窗和背景声音后比较。
- 家电：固定设备、距离和设置，分别观察关闭与开启状态，保持相近时长并记录档位。
- 开关窗：固定设备和位置，分别观察开窗与关窗，保持相近时长并记录外部声音变化。
- 区块标题改为“可以观察哪些声音变化？”及英文对应说明，英文第三项明确写出开关窗，不再使用笼统的 “Check a change”。
- 三个例子使用无序列表，每项内部使用原生两步有序列表；移除整卡 Link、目标配置、装饰性大编号、底部箭头与条件标签，以及整卡悬停、抬升、聚焦和按压样式。图标、主题表面与三个同级例子的关系保留。
- 680px 以上三列，680px 及以下单列。区块标题 24px、场景标题 20px、操作正文 16px、列表序号 14px；手机保持字号和完整文字，通过自然换行适配。
- 内容与展示仍在 HomePage 服务端组件，样式在相邻 CSS Modules。没有新增客户端组件、依赖、URL 或测量逻辑。

## 工程检查与文档同步

- `scripts/check-export.ts` 补充双语首页场景区断言，禁止在说明区重新引入链接、按钮或链接角色，避免再次出现任务与目的页不对应的入口。
- 本轮检查入口为 `npm run build`（包含 TypeScript 检查）、`npm run lint`、`npm run format:check`、`npm run test:content`、`npm run test:export` 和 `git diff --check`。纯展示与链接移除使用已有静态产物检查及实际浏览器验证，未重复运行音频、统计和存储单元测试。
- 上述检查最终均通过，ESLint 为零警告；内容检查为 11 个双语正文、26 个可索引 URL 和 2 个 noindex 功能 URL，产物为 28 页、26 个 sitemap URL 和 1030 条内部链接与锚点。另核对五组浏览器数据、规格文件与文档引用，HomePage 函数低于 300 个有效代码行，涉及的三个代码文件均低于 700 行。
- 根目录 AGENTS、[首页层级 V4](../../design/home-hierarchy-v4/design-spec.json)、[场景说明 V1](../../design/home-scenes-v1/design-spec.json)、整站结构与 SEO 规划、首页关键词模块描述、首版实现说明和文档索引同步当前行为。原 [首页层级调整验证](./首页层级调整验证.md) 保留历史过程，并注明当前场景说明覆盖旧的整卡交互结论。
- 按 React 最佳实践与 simplify 复核：静态正文没有进入客户端边界；删除已失效的目标字段和交互样式，没有为简单列表新增公共组件。

## 验证边界

未验证真实移动设备、真实麦克风采集、声学准确度、远程 CI 或生产环境，本轮没有部署。
