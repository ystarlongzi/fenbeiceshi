## 设计判断与实现职责

知识页的任务是按问题找到解释或排查方法。原先四篇文章连续平铺，并在每篇重复分类标签；现在按理解读数、查询声音参考与解决使用问题分组。分类标题与文章标题分别使用固定 24px、20px，简介与摘要分别使用 16px、14px；桌面分类说明与文章并列，手机先分类后文章。保留开放排版，文章整体可点击，入门使用指南作为辅助入口。

记录页的任务是回看摘要或比较两次同条件观察。页面说明与管理工作区分开：空记录仅显示状态、主动保存的说明、开始测量及本机存储限制；有记录时显示数量、选择提示、已选数量、列表和比较结果；存储异常直接显示错误，不伪装成空记录。管理表面将选择、导出、删除和比较组织为一个任务区；选中行有底色，比较结果保留独立分区。手机备注占据完整内容宽度，读数与操作在下一行，避免长备注被挤入狭窄文字列。

| 文件                                                         | 职责与变更                                                                           |

| `src/components/knowledge-page/index.tsx` 与相邻 CSS Modules | 三组静态目录、分类说明与文章层级，继续服务端渲染                                     |
| `src/components/route-page/index.tsx` 与相邻 CSS Modules     | 记录页标题与任务说明，保持路由分派职责                                               |

样式留在所属 CSS Modules，沿用语义主题与固定字号变量；没有新增依赖、全局样式、客户端包装或测量算法。首页紧凑记录保留原有结构，空记录说明同步，未填写备注的记录不再重复显示日期。

## 记录行斑马纹与量级标签（首次六档）

本节保留首次实现及验收结果。当前标签已统一为文末的分贝对照七档，六档划分和标签颜色不再作为当前实现依据。

2026-10-19，记录行增加交替底色，支持悬停与键盘焦点背景反馈；选中记录保留复选框及左侧标记，悬停后仍可辨认。鼠标反馈仅在支持 hover 的精细指针下启用，背景过渡为 160ms；减少动画分支取消过渡，未切换系统减少动画设置实测。行本身不新增点击行为。

估算记录的数字按能量均值连续着色，并显示对应量级标签。六个边界与仪表共用 `readings.ts` 的 `NOISE_SCALE_TICKS`，名称复用双语 `estimateScaleLabels`。标签按读数的一位小数显示值判档，避免 69.99 显示为 70.0 后仍出现上一档标签；数字和导出保留原有计算与单位。

| 显示均值（估算 dB） | 标签 |
| ------------------- | ---- |
| 小于 40             | 微弱 |
| 40 至小于 70        | 安静 |
| 70 至小于 85        | 较响 |
| 85 至小于 100       | 嘈杂 |
| 100 至小于 120      | 很响 |
| 120 及以上          | 极响 |

历史 dBFS 记录使用中性的“历史相对电平”标签；输入下限记录使用“低于输入下限”，不据此判断环境安静程度。颜色和描述是产品的量级参考，不表示安全或超标结论。完整记录页显示这一说明；首页紧凑记录同步颜色和标签，仍只展示最近三条。
