# 即时读数修正验证

日期：2026-10-22。范围：本地实现，未提交本轮改动、未部署生产。

## 问题与实现

原控件只修改参考草稿，需要有效实时输入和来源才能提交；条件不满足时应用按钮不显示。浏览器复现：未测量时输入 75，主模式仍为通用估算，应用按钮数量为 0。用户已选择“直接加减当前读数，实时生效”。

现改为读数修正开关、−30 至 +30 dB 滑块／数字框、0.1 步进、即时状态与重置；不增加卡片层级，不再填写来源或提交。开始前可预设，运行中整次仪表、色带、统计和已有趋势同步换算；原始音频、采样和输入信号不变。结束后冻结结果，需重新测量后调整。空值、超范围及步长错误保留上次有效修正并提示。

`src/features/calibration/adjustment.ts` 负责纯状态与校验；`use-sound-meter.ts` 负责会话、输入变化重置和结束快照；`readings.ts` 负责统一投影；设置样式留在相邻 CSS Modules。复用既有 NumberInput、Switch，无新增依赖。应用 React best practices 的渲染派生状态、持久化版本规则，文档维护与持久化变更技能，并复核简化及文件职责；新增文件与修改函数均未触及项目规模上限。

报告保存独立 manual-offset-v1 字段。存储键不变，新写入封装版本 3，读取支持 1、2、3；旧参考与相对记录不回算。旧解析器拒绝版本 3 并保留数据，不降低版本伪造回退兼容。仅保存／删除时升级，不回填存量；IndexedDB 音频结构不变。失败与跨页写入继续使用原保留机制，重要报告回退前先导出。

## 竞品核对

三者并非都采用同一交互；只参考操作表达，不采用竞品准确度宣传。

- [OnlineDecibelMeter 校准说明](https://onlinedecibelmeter.org/zh-CN/calibration)：参考读数减当前 dBFS，需点击校准保存。
- [FreqCut 分贝仪](https://www.freqcut.cn/showinfo-1-1-0.html)：0 dB 校准系数、当前／修正后读数与应用校准按钮。
- [DecibelMeter](https://www.decibelmeter.org/zh)：校准偏移初始为 0，界面提示需要麦克风。

## 修正范围与模式标签（2026-10-22 后续调整）

按用户要求，将有效范围扩大为 −50 至 +50 dB，保留 0.1 步进、90px 输入框与隐藏步进按钮的布局。范围由 `calibration/adjustment.ts` 统一提供给滑块、数字输入和记录校验，空值、超范围及不符合步长的草稿仍保留最后有效修正。上文 ±30 的数值为之前版本的验证记录，以本节为准。

原“通用估算”和“手动修正”标签都固定带有“未校准”，容易让人误以为操作没有生效。当前默认显示“通用估算 · 未修正”，开启后显示实际修正值，例如“手动修正 · +5.0 dB”“手动修正 · −50.0 dB”；开启且为零时显示“手动修正 · 0.0 dB”，关闭后恢复默认标签。仪表、记录与报告复用 `sound-meter/mode-label.ts`，从有效投影或结果快照派生，不读取无效输入草稿。辅助说明继续明确这是估算，不代表专业校准或 dBA。简体、繁体、英文界面与指南、FAQ、工作原理、相关文章及当前产品文档同步。

估算公式、`manual-offset-v1` 模型和 v3 记录封装保持不变，正负 50 的记录可保存、读取和导出。旧版窄范围读取器会拒绝绝对值超过 30 的修正记录，回退前需导出保留，不能截断修正值伪造兼容。历史参考与相对模式继续使用原口径。
