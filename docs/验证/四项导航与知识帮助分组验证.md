# 四项导航与知识帮助分组验证

日期：2026-10-22。范围为简体、繁体与英文的主导航、知识帮助目录及所属页面高亮；本地静态产物，尚未部署生产。

## 任务与实现

原主菜单将知识聚合入口与其中的使用指南、常见问题并列，且“声音知识”名称无法覆盖工具帮助。现按测量、查询声音、学习与排查、管理记录四种任务组织导航。

- 桌面与手机统一为开始测量、分贝对照表、知识与帮助、本机记录，顺序一致。繁体为「開始測量、分貝對照表、知識與幫助、本機記錄」；英文为「Measure、Decibel chart、Knowledge & help、Records」。移除只在部分宽度隐藏帮助入口的 optional 标记和样式。
- `/knowledge/` 及对应三语页面分为工具帮助与声音知识。工具帮助保留指南、原理、常见问题三个同级卡片，麦克风排查移到卡片之后；声音知识按理解读数、查询声音参考、噪音与健康分组。说明与文章保持静态输出，没有新增客户端组件、全局样式或依赖。
- 指南、工作原理、FAQ 和读数修正页高亮知识与帮助，文章与声音详情沿用原归属；声音详情只高亮分贝对照表。目的页使用 `aria-current="page"`，所属内容使用 `location`。两份主导航最多各选中一项。
- 聚合入口名称同步到首页链接、可见面包屑、BreadcrumbList、页面标题、描述和关键词映射；关于页中的目录称呼也同步。URL、canonical、hreflang、页脚与测量过程的帮助入口保留。
- 浏览器检查发现 761px 英文页头横向溢出，紧凑桌面 761–900px 改为只显示四项完整文字，收起装饰图标。主题、语言和字号保留；901px 以上继续显示图标。

## 实际验证

执行 `rtk npm run check`，依次完成 format:check、lint、typecheck、test、test:content、build、test:export，全部通过。最新运行包含新增的两项三语面包屑测试。产物检查为 126 个页面、123 个 sitemap URL、4449 条内部链接与锚点。

新增静态产物检查覆盖每页两份主导航的四项顺序、三语名称和唯一高亮，以及目录两组内容的完整归属和无重复链接。目录检查放在 `scripts/export-checks/knowledge.ts`，避免继续扩大主检查脚本。另执行 `rtk proxy node --experimental-strip-types --test src/lib/seo/metadata.test.ts`，两项通过。
