# 国际站多语言文案精校验证

核对日期：2026-10-26。本轮在已发布的 24 种新增语言上精校搜索标题、描述、操作按钮、测量提示和 FAQ；语言、路由、页面归属与测量模型沿用原实现。

## 范围与文件

- 语言为 es、de、fr、pt-BR、ru、it、ko、ja、no、sv、da、nl、fi、el、pl、tr、id、vi、cs、hu、sk、th、ro、ar。
- 逐语言核对 47 个主题的标题和描述，以及首页与完整 FAQ 共用的 17 组问答；保留声音例子的声级范围、距离、单位与比较条件。
- 界面重点覆盖开始／结束测量、演示、实时状态、读数修正、输入下限、权限与设备错误、录音、下载、保存报告和本机记录。
- 修改位于 src/lib/i18n/messages/ 下各语言的 ui.json、knowledge.json 和 details.json。原有简体、繁体、英文源文案及用户备注、设备名不参与此次改写。
- 检查脚本位于 scripts/i18n/check-messages.mjs。没有新增依赖，没有改动布局、字体、客户端边界或部署配置。

本轮按源文与产品实际行为进行模型辅助编辑核对，不代表 24 种语言全文均已由母语编辑审校。长篇知识正文只同步与本次误译直接相关的共用句子；法规、健康与标准的来源和适用范围沿用原已核验内容。

## 主要修正

| 问题                                                                    | 本轮处理                                                               |
| ----------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Live 被译成“生活”，仪表被译成血糖仪、电表或长度单位                     | 改为实时状态与当地常用的声音／噪音测量表达                             |
| 记录被理解成唱片、运动纪录或地理上的“本地”                              | 按测量报告和本机保存的语义改写                                         |
| 输入下限被直译为地板、楼层                                              | 明确为计算或读数下限，并与零值提示对应                                 |
| 不上传、下载与录音过程的表述混淆                                        | 区分本机处理、当前页面暂存和保存到浏览器后的录音                       |
| FAQ 引用的操作名与实际按钮不一致                                        | 逐语言对应开始、通用估算、读数修正、手动修正、录音、保存和导出控件     |
| 声音描述将 flyover 译成高架桥、speaker 译成说话者、dirt bike 译成自行车 | 按飞机飞越、扬声器和越野摩托车修正；对话中的 speakers 则明确为说话人数 |
| 洗衣机“噪音范围”被译为产品系列，设备空转被译为自由奔跑                  | 按对应声音场景重写描述，保留原比较条件                                 |
| 泰语 MP3／PCM 下载按钮带有无关的 .dll 后缀                              | 删除错误后缀，保持真实文件格式名称                                     |
| 阿拉伯语将 ≤ 反译为 ≥                                                   | 还原数学关系，并对该关系使用 LTR 隔离，避免 RTL 阅读混淆               |
| FAQ 中残留英文序数 31st                                                 | 改为各语言自然表述，保留最多 30 份、第 31 份淘汰最早记录的行为         |

帮助入口另修正了将声音参考译成“可靠的参考”、将噪音暴露译成相机曝光的歧义，并缩短主要操作文字。阿拉伯语的范围、示例及单位增加方向隔离，手动修正标签增加 LTR 标记，使正负号保留在数字前。

读数修正问答继续说明 −50 至 +50 dB、默认 0、60 与 65 的例子以及 +5／+5.0 dB 状态；录音与保存限制继续对应 10 分钟、64 MiB 和 200 MiB。没有把网页估算改称 dBA、专业检测或法定检测。
