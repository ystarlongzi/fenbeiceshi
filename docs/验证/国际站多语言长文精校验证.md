# 国际站多语言长文精校验证

日期：2026-10-26。

## 本轮范围

沿用已有英文内容和原始引用，对国际站新增的 24 种语言做长文编辑复核：西班牙语、德语、法语、巴西葡语、俄语、意大利语、韩语、日语、挪威语 Bokmål、瑞典语、丹麦语、荷兰语、芬兰语、希腊语、波兰语、土耳其语、印尼语、越南语、捷克语、匈牙利语、斯洛伐克语、泰语、罗马尼亚语和阿拉伯语。

覆盖使用指南、工作原理、读数修正、准确性、隐私和本机存储、专业检测选择、降噪、听力保护、噪音健康、中国大陆法规、职业标准及声音详情。正文、小标题、场景说明和来源条件均在词典中维护；去掉上一轮搜索文案和完整 FAQ 后，清单包含 890 条共用内容，其中 325 条为较长段落。

本轮属于模型辅助的编辑与语义复核：德语、西班牙语、法语进行了正文通读；其他语种重点逐语对照技术、隐私、健康、法规和声音条件等高风险段落，并按同类问题修订相关条目。全部词典执行完整性检查。尚未完成 24 种语言逐篇全文的母语人工审校，不新增或虚构审稿人、专业认证、搜索量或排名结论。

共修订 1777 条词典内容，其中 1610 条位于知识正文和声音详情词典，其余为相关界面词典中的静态说明、表格及控件名称。

## 修订结果

- 区分声音吸收、隔音和减振；修正把声学交换率写成汇率、把 A/C 计权写成空调、把 PCM 有符号整数写成签名音频等术语错误。
- 保留 RMS dBFS 与声压级的区别、`generic-rms-v1` 的 `+100` 产品假设、手动修正范围与非累加关系；不把网页估算写成 dBA、校准结果、合规证据或个人安全时长。
- 明确音频不发送到服务器、本机可选录音与下载仍可用；保留 10 分钟、64 MiB、200 MiB、30 份报告、删除关联音频及存储异常的原有边界。
- 修正声音详情中的测距、设备名称、空载运行、送风口、耳鸣、听力变闷、不要调高音量测试等误译。保留历史资料年份、完整数值范围、0.9 米测距、5 米喇叭距离和飞机飞越条件。
- 保留中国大陆法规的法域，区分 OSHA 法定值、NIOSH 建议和欧盟行动值／限值；明确脉冲次数分段。`120+` 的零秒提示仍是本站预防性建议，不写成机构统一限值。
- 正文操作名称与实际开始按钮、模式标记同步。简体、繁体和英文同时更新过时的“国际站仅英文”“三个语言版本”说明；其他页面结构、路由、存储与测量算法未调整。

## 回归检查

`scripts/i18n/check-messages.mjs` 增加或加强以下检查：

- 所有语言的词典键、具名参数、数值、机构名和正文／界面职责。
- `dB(A)`、`dB(C)`、SPL、LAeq、TWA、NRR、微帕、模型标识和 `LEX,8h` 等保护术语。
- A/C 及独立 A、C 计权字母、比较符号；英文千位分组与无分隔整数等价，数学负号的两种字形等价，避免把排版差异当作物理量变化。
- 长文开始操作和模式标记与当前控件一致；英文序数 `31st` 不得残留在任何翻译条目中。

在只包含本轮提交范围的独立副本中运行 `npm run check`，format:check、lint、typecheck、153 项单元测试、部署测试、内容检查、两站构建和静态导出检查全部通过。部署测试 30 项通过，4 项需要 Linux／root 的演练在本机按既有规则跳过。

浏览器复核后补充修正少量职业参考用语，再次运行 `npm run format:check`、`npm run test:content`、`npm run build` 和 `npm run test:export`，均通过。最终内容检查覆盖 24 种新增语言、每种 1422 条文案，以及全站 27 种语言、1242 个可索引 URL 和 27 个 noindex 记录页。

两站最终产物为中文域 94 页、国际域 1175 页；新增语种 1128 页的正文、SEO、语言菜单、结构化数据及 38712 条内部链接与锚点检查通过。额外解析这 24 种语言的静态 HTML、排除 script/style 后，确认 1610 条修订后的文章词典内容均存在于真实正文中。

应用内浏览器实际验证：

- 德语 `/de/calibration/`：桌面正文、0 dB 起点、正负修正示例、修正范围与模式说明。
- 法语 `/fr/privacy/`：桌面隐私正文、本机音频与 IndexedDB 说明、章节目录。
- 日语 `/ja/guide/`：390 × 844 手机视口、开始操作名称、段落与目录换行。
- 泰语 `/th/knowledge/decibel-chart/51-66-db/`：同一手机视口、声音详情、0.9 米测距和 CDC/NIOSH 条件。
- 阿拉伯语 `/ar/knowledge/workplace-noise-standards/`：RTL、8 小时职业参考、A 计权及行动值／限值表述。

所测桌面与手机页面均无文档级横向溢出，截图与检查日志保存在本机 `artifacts/longform-polish/`。这些浏览器抽查不代表全部页面、全部终端或母语全文验收。未在本轮启动真实麦克风采集。

运行中仍有 npm 用户配置 `home` 的既有提示；独立副本位于仓库内部，Next.js 另提示存在多个 lockfile。它们不阻断上述检查，未为这些本机提示变更依赖或构建配置。

## 依据与边界

继续沿用页面已有引用。本轮复核的重点一手资料包括：

- [生态环境法典](https://www.mee.gov.cn/ywgz/fgbz/fl/202603/t20260313_1146496.shtml)：施行时间、噪声定义及夜间施工范围。
- [GB 12523—2025](https://www.mee.gov.cn/ywgz/fgbz/bz/bzwb/wlhj/hjzspfbz/202512/t20251211_1137517.shtml)：版本和实施状态；具体限值及适用边界沿用已有逐项核验记录。
- [NIOSH：理解噪音暴露](https://www.cdc.gov/niosh/noise/prevent/understand.html)：职业暴露建议及 3 dB 关系。
- [OSHA 1910.95 的 eCFR 文本](https://www.ecfr.gov/current/title-29/subtitle-B/chapter-XVII/part-1910/subpart-G/section-1910.95)：联邦一般工业适用范围；OSHA 页面本轮读取返回 403，使用官方 eCFR 文本复核。
- [欧盟职业噪声指令](https://osha.europa.eu/en/legislation/directives/82)：行动值与考虑实际保护效果的限值。
- [NIDCD：噪声性听力损失](https://www.nidcd.nih.gov/health/noise-induced-hearing-loss)及[突发性耳聋](https://www.nidcd.nih.gov/health/sudden-deafness)：听力影响、耳鸣及突发听力下降及时就医的原有表述。
- [WHO：环境噪声](https://www.who.int/tools/compendium-on-health-and-environment/environmental-noise)：环境噪声健康影响的群体研究背景。

没有把上述职业标准改写为各语言所在地的法律，也没有以浏览器读数推断个人健康或法规符合性。未在本轮重做跨设备声学校准、真实录音和专业检测验证。
