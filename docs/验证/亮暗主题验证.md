# 亮暗主题验证

日期：2026-10-17。范围为中英站点主题、偏好记忆和相应隐私说明；只更新本地实现，没有部署生产。

## 设计与实现

- 浅色外壳延续现有浅绿体系；暗色采用多层深绿表面、浅色正文和绿色操作强调，保留工作区、步骤、场景、阅读区与 FAQ 的关系。仪表、输入电平色带和噪音参考量表保持固定的深绿读数配色。
- `src/app/globals.css` 维护基础色、语义表面/文字/边界/状态变量；11 个既有 CSS Modules 迁移相关颜色。趋势曲线、填充和坐标文字跟随主题，真实与演示曲线继续区分。
- `src/components/theme-switch` 独立负责同步首屏脚本、客户端切换和订阅。站点外壳、首页与正文继续由服务端渲染；仅根节点允许引导脚本造成的主题属性差异。
- 首次没有有效偏好时跟随系统，手动切换只保存 `fenbeiceshi:theme:v1` 的 `light` 或 `dark`。刷新、中英及页面跳转保持选择，同源标签页响应 storage 事件；清空偏好后恢复跟随系统。与本机摘要使用不同键，不操作音频状态。
- 存储读取受限时标记不可持久化并使用系统外观；手动写入失败仍应用当前主题，返回包含原因的错误并显示无法记忆的提示。非法持久化值只作为缺失偏好处理，不写入 DOM。
- 太阳与月亮复用 Lucide 固定提交及现有许可证，原始 SVG 与来源保存在 `design/theme-v1/icons`。没有新增依赖。

## 实际验证

`npm run check` 通过：格式、ESLint（0 警告）、strict 类型、22 项测试、双语内容、构建及静态产物检查。新增 6 项主题测试覆盖首屏白名单和优先级、读取受限、持久化失败、系统变化、跨标签同步和取消订阅、服务端无浏览器环境。现有 16 项采集、校准与记录测试继续通过。

实际浏览器为 Codex 内置浏览器，覆盖桌面 1303×1050、中文 390×844、英文 320×740：

| 项目       | 实际结果                                                                                               |
| ---------- | ------------------------------------------------------------------------------------------------------ |
| 首次与刷新 | 无偏好首次显示系统亮色；选择暗色后刷新仍为暗色，按钮状态与太阳图标一致                                 |
| 页面覆盖   | 首页工作台及下半部、知识索引、带表格文章、记录空态和 404 均检查；主题保持一致                          |
| 中英与手机 | 切换语言后保持暗色；320px 收起品牌文字，390px 保留文字，菜单与切换按钮无横向溢出；中文开始按钮仍在首屏 |
| 键盘       | Enter 可切换主题，aria-pressed 随当前外观更新                                                          |
| 标签页     | 实际打开临时同源标签页，在其中切到亮色后，原标签页同步更新；检查后关闭临时标签页                       |
| 会话与曲线 | 演示运行中切换主题后仍为演示，趋势持续显示；暗色演示曲线为浅蓝、坐标为浅灰绿，退出演示后恢复等待       |
| 控制台     | 常规页面未捕获 error/warn，未发现水合错误；另行访问不存在的 URL 检查 404 外观与返回操作                |

手动切换的亮暗偏好已同步到中英隐私正文。主题引导位于可见内容之前，但没有记录首屏绘制时间或逐帧性能数据，不据此承诺量化的闪烁或性能指标。存储受限和系统深色变化通过测试环境模拟验证；没有更改用户的系统外观或浏览器权限。
