# 帮助内容与标题优化验证

日期：2026-10-21。范围为本地中英文首页、常见问题、工作原理、相关标题与帮助入口，生产尚未部署。

## 内容与层级

- 首页测量继续为主任务，知识区增加通俗工作原理导读，FAQ 从 3 问扩展为 8 问。
- `/faq/` 与 `/en/faq/` 按开始使用、准确性、麦克风、读数、测量方法、录音与记录六组展示 17 问。首页与完整页共用 `src/lib/content/faq.ts` 和服务端 `FaqList`，避免双份答案漂移。
- `/how-it-works/` 与 `/en/how-it-works/` 以采集、能量计算、估算映射和趋势统计四步说明原理，再介绍设备差异与本机音频处理。公式详解仍在原有文章，既有路径与章节 ID 保留。
- 使用指南、校准、准确性、读数差异、麦克风排查、知识目录与记录页标题采用直观问题或任务；没有改变估算模型、采集、存储与导出行为。
- 常见问题进入主导航与首页，工作原理在首页知识区、知识目录与页脚提供入口。手机抽屉保留六项导航，761–1140px 收起使用指南和 FAQ 两项。
- 新增四个真实中英文 URL，总计 28 个，其中 26 个可索引、两个记录页 noindex。canonical、语言关系、sitemap 继续从页面注册派生。

## 来源与功能核对

原理对照 `capture.ts`、`level.ts`、`readings.ts` 与现有校准、录音、报告说明；外部核对 [MDN getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)、[MDN 数字采样](https://developer.mozilla.org/en-US/docs/Web/API/AnalyserNode/getFloatTimeDomainData) 与 [NIOSH 特定应用验证条件](https://www.cdc.gov/niosh/noise/about/app.html)。通用 +100 继续明确为产品估算假设，没有跨设备声学精度验证，不将采样幅值当作真实声压。

保留录音默认关闭、10 分钟／64 MiB 单次限制、200 MiB 本机音频总量、30 条报告、独立音频下载与后台停止等实际边界。候选问题没有加入竞品的固定误差、永久免费或专业取证承诺。
