# 分贝对照页摘要样式验证

日期：2026-11-23。本文保留摘要实现阶段的本地 Web 验证；当前已随 `9d685b6` 与中文详情、法规改稿一起发布到生产，实际版本及线上验收见 [中文 SEO 与摘要样式上线验证](./中文SEO与摘要样式上线验证.md)。

## 层级判断与调整

页面的主要任务是查询常见声音量级，摘要帮助读者先建立直观印象；搜索与七档声音组继续作为主要内容。原摘要是一行没有角色标识的正文，四个绿色数值链接较醒目，且正文布局间距与首章顶部内边距叠加，导致摘要、目录和第一章之间不够连贯。

现将摘要组织成单层浅底分组，以小号「摘要」标识说明内容角色，细侧线与现有主题相接。桌面标识与正文并列，手机将标识放在上方，给句子保留完整行宽。数值跟随正文颜色，以细下划线提示可点击；四个例子优先按完整意思换行，分贝范围与单位保持同行。摘要靠近更新信息，并去掉中文首章重复的顶部留白。

## 实现范围

- `src/features/decibel-chart/index.tsx` 与相邻 CSS Modules 负责摘要结构、主题样式和手机顺序；通过现有 `ContentPage` 的 `className` 与 `sectionClasses` 入口调整首章间距。
- `src/lib/content/decibel-chart.ts` 显式维护简繁摘要标识，将既有文案按前缀、数值链接与后缀组织。普通文字摘要仍由相同片段生成，原句、单位及目的页保持一致。
- `scripts/export-checks/chart-overview.ts` 在原有静态链接、内容及位置断言之上，检查摘要标识与正文分组；英文继续检查没有中文专属摘要结构。
- 本次不增加路由，不修改标题、description、canonical、hreflang 或关键词归属；仅同步当前视觉规格与项目入口，已上线的 SEO 与导航记录仍作为前一版本记录保留。

## 验证结果

`npm run check` 通过：Prettier、零警告 ESLint、TypeScript strict、183 项应用测试、31 项部署脚本测试、24 种新增语言各 1431 条词典校验、27 语内容检查、双站构建及静态产物检查。4 项真实 Linux／Nginx 部署演练按本地配置跳过。本轮没有修改依赖或发布脚本。

静态检查覆盖 1269 个 URL、1242 个可索引页面及 27 个 noindex 记录页；摘要标识与分组、原生详情链接、原单位、目录前位置及英文回归均通过。另以已上线原文对比简繁 `takeaway`，两者逐字一致。完整输出位于 `artifacts/chart-summary-20261123/check.log`。

使用静态产物的 `npm run preview` 与英文对应预览，在 Codex 内置 Chromium 完成以下检查：

- 1280×720 简体与繁体桌面：摘要标识与正文并列，标识 12px、正文 16px；摘要与元信息相距 18px，摘要底部至首章标题为 35px。见 [简体桌面截图](../../design/decibel-chart-summary-v1/desktop.jpg)。
- 375×812 简体手机：标识位于正文上方，四个例子完整成组换行，正文保持 16px；文档宽度为 375px，摘要仍在目录前。见 [手机截图](../../design/decibel-chart-summary-v1/mobile.jpg)。
- 320×740 简繁深色：文字、浅底与细侧线使用主题变量，正文保持 16px；每个例子、范围与单位完整，文档宽度为 320px，没有页面横向溢出。见 [繁体深色窄屏截图](../../design/decibel-chart-summary-v1/traditional-dark-320.jpg)。
- 按 Tab 从 30 dB 进入 40 dB 链接，焦点显示 2px 实线轮廓；按 Enter 实际打开 40 分贝详情，核对 URL 与 H1。
- 1280×720 英文保留原摘要及 Decibel guide，没有新增中文专属摘要分组。最终静态预览的控制台错误为空；验证后恢复「跟随系统」，清除临时视口覆盖。

浏览器原始记录保存在 `artifacts/chart-summary-20261123/browser-checks.json`。按 React 性能规范与 simplify 复核，摘要继续服务端静态输出，组件专属样式留在相邻 CSS Modules；未增加客户端状态、共享组件接口、第三方依赖或全局样式。修改模块均在项目规模限制内。

手机检查为浏览器视口模拟，真实设备与其他浏览器内核未覆盖。摘要样式这一部分不涉及麦克风、录音、测量模型、健康与法规事实；同批法规改稿的来源复核见 [中文详情与法规验证](./中文详情与法规SEO调整验证.md)，生产发布记录单独维护。
