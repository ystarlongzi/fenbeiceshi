# 首页精选文章调整验证

日期：2026-10-24。范围：本地 Web，尚未部署生产。

## 任务与内容关系

首页的主要任务是完成一次声音观察，声音知识帮助读者进一步理解读数。原列表直接遍历全站文章，实际展示 37 篇，其中包含 28 篇分贝详情；左侧同时放总导读、原理和健康入口，导致左右关系不清。

知识区统一为「测完之后，怎么看？」：左侧只有总导读与「查看全部知识与帮助」；右侧依次回答三个同级问题。

| 阅读问题               | 目的页     | 简短说明                                 |
| ---------------------- | ---------- | ---------------------------------------- |
| 这个读数，大概有多响？ | 分贝对照   | 理解常见声音的大致量级与比较条件         |
| 手机测分贝，准吗？     | 手机准确性 | 认识设备和条件的影响，区分估算与专业检测 |
| 噪音会怎样影响健康？   | 噪音与健康 | 了解健康影响与减少暴露的方法             |

列表固定为三项，首页专属标题与短说明在相邻 `copy.ts` 中提供三语文案；原理、单位详解及其余文章通过知识目录和原有帮助入口按需阅读。桌面保留主辅布局，手机先总导读再阅读列表；去掉独立导读及其样式，不添加嵌套表面、客户端状态或依赖。

## 实现与回归检查

- `src/components/home-page/index.tsx` 负责静态语义结构与链接，`copy.ts` 统一总导读和三项内容，`index.module.css` 继续维护原有排版与响应式。
- `scripts/export-checks/knowledge.ts` 校验三语静态 HTML 中的总导读、唯一目录入口、三个文章目标及其顺序，并限制知识区只保留这四个链接；由 `scripts/check-export.ts` 调用。
- 设计规格、首页关键词分工和项目约定同步更新；全部文章、声音详情和路由仍由原注册表维护。

## 自动化验证

`npm run check` 全部通过：Prettier、零警告 ESLint、TypeScript strict、144 项测试、44 个三语正文检查、生产构建及静态产物检查。结果为 141 个页面、138 个 sitemap URL、4,839 条内部链接与锚点。三语首页均通过总导读、单个目录入口及三个阅读目标的静态断言。

npm 仍输出既有的 `Unknown user/env config "home"` 提示。构建后已恢复 `next-env.d.ts` 原有的本地开发类型路径差异；它不属于本轮修改。

## 实际浏览器验证

在 Codex 内置 Chromium 中完成以下检查，原始结果见 [浏览器记录](../../design/home-hierarchy-v4/knowledge-selection-checks.json)：

- 1280×720 简体桌面：左侧只有总导读与目录入口，右侧三问与导读顺序一致。整个知识区约 474px 高，包含四个阅读链接。
- 390×844 简体手机：先总导读，再依次展示三问；整个知识区约 709px 高，文档宽度为 390px。标题保持 20px，描述保持 16px。
- 320×740 英文深色：总标题、三问和短说明均完整，字体仍为 20px／16px，文档宽度为 320px，链接全部使用 `/en/` 路径。
- 320×740 繁体：使用独立繁体文案，三问顺序一致，文档宽度为 320px，链接全部使用 `/zh-tw/` 路径。
- 简体桌面分别实际点击三篇文章和完整目录，均核对目的 URL 与 H1；另核对英文健康入口及繁体目录入口的实际跳转。
- 检查后恢复「跟随系统」，清除视口覆盖并关闭临时标签页。

截图：[桌面知识区](../../design/home-hierarchy-v4/knowledge-selection-desktop.png)、[完整手机知识区](../../design/home-hierarchy-v4/knowledge-selection-mobile.png)、[英文深色窄屏](../../design/home-hierarchy-v4/knowledge-selection-mobile-en-dark.png)。

按 React 性能规范保持服务端静态输出；按 simplify 复核，复用现有文案文件、路由与列表样式，移除不再使用的导读样式和文章全文索引依赖。文件及函数均在项目规模限制内，没有新增客户端状态、共享抽象或第三方依赖。手机验证为视口模拟，未验证真实手机及其他浏览器内核；本轮不涉及麦克风、录音或测量模型。
