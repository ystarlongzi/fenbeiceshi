# 文章目录锚点高亮验证

日期：2026-10-18。范围：本地静态预览，适用于共用 `ContentPage` 的 8 个双语正文、共 16 个 URL；未部署生产。

## 任务与实现

文章正文承载连续阅读，目录辅助定位。原目录项样式一致，滚动后无法识别当前章节。本轮仅将目录提取为局部客户端组件，以底色、加粗文字、2px 侧边标记和 `aria-current="location"` 表达当前阅读位置；亮暗配色复用已有主题变量。桌面继续使用固定侧栏，手机继续使用正文前的换行目录。

- 目录组件、样式、位置判断与测试位于 `src/components/content-page/table-of-contents/`；`ContentPage` 仅传入章节 ID 和本语言标题。
- 高亮依据实际滚动位置，复用现有 `scroll-padding-top` 与 `scroll-margin-top` 的合计偏移；处理不足一个 CSS 像素的定位误差、长章节及页底短章节。
- 滚动监听使用 passive 和 `requestAnimationFrame` 合帧，仅保存当前章节 ID；`ResizeObserver` 处理声音筛选等正文高度变化，卸载时清理监听、观察器和待执行帧。
- 点击与深链接沿用原生锚点和历史行为。手动滚动不改写地址，也不增加历史记录。正文、来源和全部目录链接继续进入静态 HTML；未新增依赖。

按 `vercel-react-best-practices` 约束客户端边界、传递字段、派生状态及滚动监听，并按 `simplify` 复核局部实现与中文原因注释。页面结构、字号和全局样式继续沿用现有约定；文档同步遵循 `documentation-update`。
