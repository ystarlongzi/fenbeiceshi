# 全站字号调整验证

日期：2026-10-18。范围为全部 22 个中英页面、共享外壳、测量工具、设置、记录与 404 页的字号和排版；未部署生产。

## 规则与实现

- `src/app/globals.css` 统一维护固定 `rem` 字号变量：辅助文字 12px、界面文字 14px、正文 16px、小标题 20px、模块标题 24px、页面标题 32px，数值以浏览器默认 16px 基准换算。保留浏览器缩放和用户默认字体设置，不锁定根字号。
- 删除字号中的 `clamp()`、`vw` 与手机断点的字号覆盖；断点只调整布局、间距及图形尺寸。普通内容至少 12px，本轮没有保留小于 12px 的例外。
- 首页说明、文章正文与列表说明使用 16px；主要按钮、导航、目录、表格和常规说明使用 14px；仪表样式切换按钮、设置辅助说明和设备名称使用 12px；未校准提示、权限错误、演示限制和隐私说明使用 14px；日期、单位和辅助标签至少 12px。表单输入使用 16px。
- 普通仪表读数固定 72px，数显固定 80px，全屏观察读数固定 88px，只按观察模式切换。窄屏允许读数单位、操作和状态自然换行。
- 指针仪表的刻度文字移出 SVG，改为固定 12px 的 HTML 覆盖层；位置仍来自原仪表坐标。新增外层只用于对齐刻度和图形，静态刻度数据在模块初始化时计算。
- 样式继续留在相邻 CSS Modules。共享外壳调整导航间距、窄屏排列与辅助导航收起位置；测量操作、结果操作、记录标题和趋势标题允许换行。没有新增依赖、路由、采集逻辑或存储格式。
- 当前规则已写入根目录 `AGENTS.md`，覆盖早期设计规格中的字号数值；历史设计资产不批量改写。

## 辅助字号微调

全站调整后进一步收紧测量工具的辅助层级，复用 `--font-size-caption`，不改变全局正文和标题字号：

- `sound-meter/index.module.css` 的 `.views button` 固定为 12px，中英指针、数显、条形切换使用同一规则。
- `meter-settings/index.module.css` 的 `.settingGroup p` 和 `.inputLabel` 固定为 12px，用于设备说明、校准辅助说明、观察条件说明和设备名称。
- `.inputWarning` 显式保留 14px，主读数附近的未校准说明、错误提示和主要操作继续使用原字号。
- 不增加断点字号覆盖，不缩小按钮的内边距或手机最小高度。

本次微调重新运行 `npm run build`、修改文件的 Prettier 检查和 `git diff --check`，均通过。未重跑首轮的 27 项逻辑测试。内置浏览器在 1280×900、390×844、320×740 下分别检查中英首页，共 6 次检查：切换按钮和设置辅助段落均为 12px，没有小于 12px 的内容或页面横向溢出。中文手机另实际切换指针/数显并展开参考校准，操作和排版正常。

本次数据见 [微调检查数据](../../design/typography-v1/browser-refinement-audit.json)，截图为同目录 `screenshots/` 下的 `desktop-compact-controls-1280.jpg`、`mobile-compact-controls-390.jpg` 和 `mobile-compact-settings-390.jpg`。本次为模拟手机视口，未触发真实输入处理告警或请求麦克风；告警字号由显式 CSS 规则保留。
