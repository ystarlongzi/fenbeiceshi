# 分贝详情量级对比与通俗文案验证

日期：2026-10-22。范围：28 个既有主题的三语内容与共用详情模板；本地实现，未部署。

## 依据与调整

重新实际浏览 [竞品 40 分贝页](https://www.decibelmeter.org/zh/comparison/40-db)。它用分贝变化、体感和能量直接比较量级，听力标题先提问，常见问题从卧室、冰箱和音量差等日常问题切入。本站 V2 只并列声音资料，缺少相差多少的解释；听力及问答较多从测量术语和限制开头。

本轮保留首屏和章节层级，仅调整以下内容：

- 量级对比采用五行三列：降低 10／3 分贝、本页参考、提高 3／10 分贝。40 页对应 30、37、40、43、50；47–72 页对应完整范围的两端一起变化。表中标明听感近似值及声音能量比，以本页为 1 倍参照。
- 听力标题改为“×× dB 对听力有害吗？”，先回答风险，再给日常行动；按低声级、范围高端、强声和突发烟花区分，未给出个人安全时长。
- 每页两条专属问答及共用手机问题，三语均单独编写。40 页先回答卧室是否觉得吵，以及冰箱标注和家中听感不同的原因；保留原有问答锚点与来源。

## 内容准确性与实现

本轮重新核对 [NIDCD：How Loud is Too Loud?](https://www.nidcd.nih.gov/health/how-loud-too-loud)、[NIDCD：Noise-Induced Hearing Loss](https://www.nidcd.nih.gov/health/noise-induced-hearing-loss)、[CCOHS：Noise — Basic Information](https://www.ccohs.ca/oshanswers/phys_agents/noise/noise_basic.html) 与 [NIOSH](https://www.cdc.gov/niosh/noise/about/noise.html)。10 分贝变化的两倍听感为近似经验。数字表中的听感倍数按 2^(ΔdB/10) 的模型近似，声音能量比按 10^(ΔdB/10) 计算，两者保留两位有效数字；听感小数是该模型的插值，不代表每个人的精确感受。

对比表演示的是同一声音、相同测法和单位下的相对变化，不比较不同场景的实测听感。范围两端一起移动，保留原始范围宽度；原有 31 项声音数值、dB／dBA、来源与 URL 均不变，不新增 50 等整数详情页。100 页的吹风机与雷声仍分别保留 dB 和 dBA。强声数字仅供阅读，不播放声音或要求用户靠近复现。

`comparison.ts` 负责相对变化数据，场景问答仍靠近原主题内容；`guidance.ts` 负责共用听力与手机说明。展示与 CSS Modules 留在详情功能目录，正文与表格静态输出，未新增客户端状态或第三方依赖。

- Chrome 桌面 1440×1000 检查 40 页，手机视口 390×844 检查 40、繁体 100 和 140–160 页，320×812 检查英文 47–72 页。表格无横向溢出，当前行突出显示，范围完整；英文、繁体及暗色内容均可读。

- 实际点击量级表来源可定位 NIDCD 引用，目录可定位对比、听力和常见问题；三项答案直接显示。键盘和实际读屏设备未作完整验证。
- 按 `simplify` 复核数据与展示职责，删除已被取代的场景对比数据和旧问答字段；复用原范围格式、来源及静态内容组件，无新依赖。涉及文件均少于 700 行有效代码，函数少于 300 行。`rtk git diff --check` 通过。
