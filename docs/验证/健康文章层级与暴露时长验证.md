# 健康文章层级与暴露时长验证

更新：2026-10-20。范围：健康文章的中英文页面，本地实现与静态预览；尚未部署生产。

## 本轮调整

原先职业暴露演示位于第二章折叠项中，用户需要先阅读长篇影响说明。现在将它作为第一章默认展开，文章顺序调整为：

1. 暴露时长：手动输入、滑块、即时结果与六个常用参考点。
2. 影响概览：听力损伤、耳鸣与听觉发闷、睡眠干扰、烦扰与专注、心血管风险、儿童与敏感人群。
3. 减少干扰：保留三项行动，紧接影响概览。
4. 理解暴露：集中解释测量条件、长期研究与个人判断的区别。
5. 专业帮助：保留听力检查与相关评估入口。

健康主题采用“短标题、一段说明、就近来源”，桌面双列、520px 及以下单列。此处容器表示六个同级主题；其余正文仍采用开放章节，行动保留连续列表。原有中英 URL、章节锚点和对照页入口不变，没有新增页面或搜索意图。

## 竞品参考与事实依据

实际读取和操作了 [realtimesoundmeter.org 中文页](https://realtimesoundmeter.org/cn/)：数字输入与滑块同步、即时显示时长，并列出常用参考值。100 的操作结果为 15 分钟。本站采用这种操作关系，将单位和范围限定为独立手动的职业参考示例，不采用“无限安全”等表述。

实际读取了 [realtimesoundmeter.com 中文页](https://realtimesoundmeter.com/zh/) 的 `.health-impact-grid`：桌面三列六项，每项短标题加一段说明。本站适配现有 750px 文章列，使用双列，并重新按官方依据组织六个主题；没有照搬其夜间 40 分贝或压力激素等结论。

## 职业参考的计算与边界

公式为 `T = 480 × 2^((85 − L) / 3)`，T 单位为分钟，L 为手动输入的 dBA。基准与交换率来自 NIOSH 职业听力保护参考，按持续处于同一声级累计计算。

- 演示范围为 85–115 dBA，步长 0.5，默认 85。这个范围是本站的教学交互选择，不表示标准只覆盖此范围。
- 六个参考点为 85／88／91／94／97／100 dBA，分别对应 8／4／2／1 小时、30／15 分钟，点击后同步输入与滑块。
- 结果向下取整到秒；至少一小时显示小时和分钟，不足一小时可显示分钟和秒。115 dBA 的计算结果约 28 秒，不会因按分钟取整而消失。
- 空输入、越界、非有限数及不符合步长的值显示就近错误，结果变为“—”，不保留上一次结果。
- 结果标记为每日累计“参考时长”，不是个人安全倒计时、卧室目标或冲击声阈值。混合声级及个体差异需要单独评估。
- 不读取麦克风或本站仪表估算，不把未校准的通用噪音估算转成 dBA。

## 实现职责与技能应用

`src/lib/content/noise-health.ts` 管双语章节、六项说明和来源；`src/features/noise-health/index.tsx` 保持服务端文章展示；客户端交互仅位于相邻 `exposure-explorer/`，计算与输入校验由其 `model.ts` 负责。专属样式留在各自 CSS Modules，没有新增依赖或全局样式。

按 React 最佳实践保留小型客户端边界，结果由当前输入直接推导，不新增同步 Effect 或重复状态。按 `simplify` 复核此次范围，移除旧折叠入口与不再需要的锚点增强组件，复用范围常量和校验规则。按文档维护技能同步 AGENTS、页面与关键词映射、整站规划、文档索引及 [V2 规格](../../design/noise-health-v2/design-spec.json)。

修改文件均围绕健康文章、校验脚本与维护文档；单个文件和函数没有接近项目规模阈值。

## 实际浏览器检查

使用 Chrome 实际渲染静态产物，预览端口 3144。证据见 [浏览器检查记录](../../design/noise-health-v2/browser-checks.json)。

- 桌面 1440×1100：时长默认可见；影响区为 367px 双列，六项正文和来源可读；目录锚点高亮随新顺序变化。
- 手机 390×844：输入、滑块、结果顺序排列，参考点为两列且按钮至少 48px 高；影响区为 350px 单列，没有横向溢出。
- 英文暗色手机 320×740：结果保留 32px、正文 16px、必要条件 14px；较长时长和主题说明正常换行，没有横向溢出。
- 数字输入与滑块同步，实测 85／88／91／100／103／112／115／85.5；分别得到 8 小时／4 小时／2 小时／15 分钟／7 分钟 30 秒／56 秒／28 秒／7 小时 7 分钟。
- 空值、84.5、115.5、85.1 均显示错误并清空结果；100 dBA 参考按钮同步至 15 分钟；滑块 Home 后方向键可到 85.5。
- 英文默认 8 hrs，103 显示 7 min 30 sec，115 显示 28 sec；暗色主题仍可辨识输入、焦点、结果和来源。
- 控制台记录到用户浏览器扩展脚本的 TypeError，以及异步 listener/message channel 提示；本轮交互未见对应功能异常，未禁用用户扩展复测。
