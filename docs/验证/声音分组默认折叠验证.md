日期：2026-10-22。范围：简体、繁体与英文的分贝对照页；本地实现，未部署生产。

## 行为与层级

- 七档默认只显示范围、程度名称和体感说明，点击分组摘要后显示该档声音标签；各档独立展开。
- 声音描述继续使用原生 `details`，默认收起，同档同时展开一项，保留来源入口。
- 搜索自动展开匹配分组，仍可手动收起；修改搜索词后展开新结果，清空搜索后七档恢复折叠。
- 分组也使用原生 `details`，保留键盘操作及无脚本展开。31 项声音的名称、范围、单位、描述及来源仍存在于初始 HTML。
- 折叠功能交付时尚未创建数值详情页。随后已完成全部 31 项描述的段落行内入口与 28 个详情主题，见 [分贝详情与行内链接验证](./分贝详情与行内链接验证.md)；本记录保留折叠功能当时的检查结果。

### 阴影加深与过渡补充

按后续反馈，将整档悬停阴影改为两层：`0 8px 22px` 使用主题阴影与 10% 黑色混合，`0 2px 6px` 沿用主题阴影。基础状态声明 `box-shadow 200ms ease-out`，保证移入和移出均有过渡；`prefers-reduced-motion: reduce` 下关闭过渡。只动画阴影，保持原布局、配色与标题无下划线。

参考 `transitions-dev` 的悬停反馈、限定动画属性和减少动画偏好原则，沿用局部 CSS Modules，不增加脚本或动画依赖；按 `simplify` 复核改动范围。Chrome 1440 × 1000 实际检查浅色移入、移出和暗色展开状态，计算过渡属性均为 `box-shadow`、`0.2s`、`ease-out`，移出后恢复无阴影。两层阴影的浅色主层透明度由约 8% 增至约 17%，暗色主层为约 27%。验收后恢复浅色和默认视口。

本轮 `rtk npm run build`、`rtk npm run test:export`、定向 Prettier 和 `rtk git diff --check` 通过。定向静态检查确认减少动画规则、目标属性和两层阴影；没有切换系统的减少动态效果偏好，未重复真实手机、Safari 或全套检查。
