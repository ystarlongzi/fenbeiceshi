# 分贝对照页内容精简验证

验证日期：2026-10-20。范围为中英文 `/knowledge/decibel-chart/` 的本地实现；设计依据见 [V4 规格](../../design/decibel-chart-v4/design-spec.json)。

## 层级判断与调整

页面的主要任务是查找常见声音与分贝量级。原页面将七档、31 项声音、40–70 分贝表、对数原理、职业演示、六类健康主题和使用限制依次展开，查询入口还有两套数值控件与多段重复说明。

- 主目录由八项收为分段概览、声音查询、读数说明、健康影响四项。
- 声音名称与数值共用现有搜索框；数值输入和滑块改为可选展开区。单位、距离与网页估算的区别仍在查询前直接可见。
- 默认完整显示 31 项声音，保留数值、单位、条件与来源；移除每行重复的类别标签，类别筛选继续可用。
- 40–70 分贝、对数原理、职业暴露、比较方法和读数限制归入五项按需问题。职业参考表与演示仍在同一问题内，演示继续独立于仪表与声音选择。
- 健康卡片改为六行原生展开列表，展开后显示摘要、背景、行动和来源；页首保留单次网页读数不能判断个人健康风险的说明。
- 固定字号、七档名称、量级配色与完整静态正文保留。未增加依赖、路由或健康结论。

默认页面长度实测，均为中文亮色、无筛选、按需区域关闭：

| 视口       | 调整前   | 调整后  | 减少   |
| ---------- | -------- | ------- | ------ |
| 1748 × 817 | 9,282px  | 5,489px | 约 41% |
| 390 × 844  | 12,766px | 7,375px | 约 42% |

最终另验证了 1280 × 960 中文桌面，默认 31 项声音、四组目录、无页面横向溢出。页面长度是本次浏览器环境的布局结果，不是跨设备固定值。

## 文件职责与实现复核

- `src/lib/content/decibel-chart.ts` 分开维护四组主内容与五项说明；原有说明锚点全部保留。
- `src/features/decibel-chart/chart-notes/` 负责按需正文与表格；正文为服务端组件，`note-anchors.tsx` 仅负责片段定位，不将文章转为客户端渲染。
- `sound-reference-list/` 负责主搜索、类别、可选滑块和结果反馈；`sound-overview/` 调整局部间距与提示；`health-effects/` 负责健康展开列表。
- 原页面入口中的来源链接样式随说明迁入 `chart-notes/index.module.css`，删除不再使用的页面样式文件；没有改动通用文章模板和全局样式。
- `scripts/check-content.ts` 增加说明的双语字段与锚点唯一性检查；`scripts/check-export.ts` 验证默认折叠、说明及表格仍在静态 HTML、原有锚点和完整声音、健康正文与来源。
- 同步 `AGENTS.md`、站点规划、关键词映射、文档索引及 V4 规格；路由、关键词归属与本地未部署状态不变。
- 应用了 `redesign-existing-projects`、`vercel-react-best-practices`、`documentation-update` 与 `simplify`。复核了服务端正文、局部交互、中文注释、CSS Modules 归属和文件规模；本轮涉及的业务文件及函数均未接近项目规模阈值。

## 实际浏览器验证

通过 Chrome 访问本地静态预览，覆盖桌面 1748 × 817、1280 × 960，中文手机视口 390 × 844，英文手机视口 320 × 740；覆盖亮暗主题。结束时恢复亮色并清除交付标签的临时视口覆盖。

| 验证                          | 结果                                                                                 |
| ----------------------------- | ------------------------------------------------------------------------------------ |
| 中文 70–85 分段               | 7 / 31 项，焦点移至结果数量                                                          |
| 搜索 60 并选择家电            | 2 项；无匹配名称变为 0 项；重置恢复 31 项并聚焦搜索框                                |
| 滑块入口键盘 Enter、输入 200  | 能展开；无效输入标记、0 项与恢复入口可见；手动折叠后仍能重置                         |
| 滑块从 59 按方向键增加        | 输入与滑块同步为 60，3 项，焦点保留在滑块                                            |
| 声音选择 60，职业演示输入 88  | 职业输出 4 小时，声音条件与 3 项结果保留；职业输入 70 显示错误与无结果               |
| 五个原有说明锚点              | 均能展开并定位；新标签直接打开英文 `#numbers` 稳定展开，刷新说明后仍保持对应内容可见 |
| 健康主题键盘展开              | 中文睡眠与英文长心血管标题可展开，背景、行动与来源可读，正文保持 16px                |
| 手机 30–50 分段与 60 dBA 搜索 | 分别 4 项与 1 项；结果定位在页头下方，单位查询只保留正常交谈                         |
| 英文 320px 表格与 140 查询    | 3 列表头正常换行，首列保留完整单词；140 对应 2 项；均无页面横向溢出                  |
| 目录与动态高度                | 桌面读数说明高亮对应章节，按需区开合后仍沿用原目录观察机制                           |

复测中发现折叠正文的原生片段定位在刷新后可能被水合后的状态影响；已增加挂载、`hashchange`、`pageshow` 后的局部展开处理。浏览器自身恢复已有阅读滚动位置时，保留其恢复结果；新标签直接进入说明链接时定位到目标正文。
