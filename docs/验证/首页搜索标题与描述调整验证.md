## 实现范围

- 首页三语标题与描述由 `src/lib/routing/pages.ts` 统一维护。首页使用 `|` 分隔品牌，内容页保留原分隔方式，避免首页重复拼接站点名称。
- description 同步生成页面 meta、Open Graph 与首页 WebApplication 结构化数据。首页可见 H1 和首屏说明保持原布局与文案，搜索标题作为浏览器及搜索元数据输出。
- 关键词规划保留用户补充的“分贝测试、分贝检测、在线分贝测试、噪音分贝测试、手机分贝仪、分贝测量、环境分贝检测、dB 测试”，并保留“免费在线分贝仪、在线噪音测试”；不为近义词新增 URL 或重复正文。
- 三语 canonical、hreflang、页面路径及其他页面的标题、描述与索引设置保持原行为。
- 上轮未确认的非首页草稿已撤回；恢复前的本地差异备份为 `artifacts/seo-home/previous-draft.patch`，相关草稿说明另存于同目录，不进入生产产物。JSON 只调整首页条目并保留其他页面的原排版。
- 沿用服务端组件、类型化文案与原检查入口，未新增依赖或客户端逻辑；按 React 最佳实践保留静态生成和局部客户端边界，按 simplify 复核文案复用与改动范围。
