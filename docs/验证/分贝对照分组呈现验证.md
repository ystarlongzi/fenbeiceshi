日期：2026-10-20。范围：`/knowledge/decibel-chart/` 与英文对应页；本地实现，尚未部署生产。

## 参考与任务判断

按用户指定的 [参考页](https://onlinedecibelmeter.org/zh-CN/decibel-chart)，通过 Chrome 实际查看桌面布局，并输入“冰箱”观察搜索结果。参考页用顶部搜索、七档纵向色块与组内声音标签表达量级；搜索后隐藏不匹配的分段，匹配分段中的其他标签和下方分类列表仍保留。截图见 [参考页桌面](../../design/decibel-chart-v6/reference-desktop.png)。

本轮采用七档直接承载声音的结构。浏览状态直接显示各档中的声音与数值，输入后缩小到匹配条目及其分组；条件与来源作为按需详情。主任务是对照声音量级，搜索作为定位方式，读数说明和独立健康文章继续承担后续解释。

## 修改内容与职责

- `src/features/decibel-chart/sound-reference-list/index.tsx`：删除分段选择状态和独立结果表，改为一个搜索框与七档纵向声音组。默认保留全部 31 项，声音名称、完整范围和原始单位直接可见，条件与来源用原生 `details` 展开。
- 相邻 `index.module.css`：保留 V3 七档共享实色背景与配套文字色。声音标签按内容宽度自动换行，说明在所选标签下方占满一行；所有字号使用既有固定变量，窄屏不缩小文字。
- `src/lib/content/sound-bands.ts`：七档简短名称之外，分别补充一句中英文体感说明；对照页只传入当前语言文案，仪表与记录的名称和边界保持现有定义。
- 相邻 `filter.ts` 与测试：按参考范围的起点归组，交界起点归入后一档，160 属于最后一档；跨档范围不截断，每项只出现一次。搜索只保留匹配条目及非空分组。
- 删除不再使用的 `sound-overview/` 组件与样式，避免保留另一套分段入口。
- `src/lib/content/decibel-chart.ts`：同步中英文描述；声音参考数值、单位与健康文章内容继续使用原有资料。
- `scripts/check-export.ts`：验证七档内容组、31 项唯一声音、默认关闭的原生详情、静态条件与来源，以及无分段按钮、类别或滑块。
- 同步 `AGENTS.md`、整站结构、关键词映射和文档索引；当前规格见 [V6](../../design/decibel-chart-v6/design-spec.json)，V5 保留为历史记录。

客户端只保存搜索输入，匹配条目与分组在渲染时派生；文章主体、全部声音与来源仍静态输出。样式保持相邻 CSS Modules，本轮未引入第三方依赖。沿用既有设计层级、React 最佳实践、文档维护与 simplify 检查，删除不用的状态、Props 和展示组件。

## 编组边界

“洗碗机 45–65 dB”等宽范围参考跨越多个分段。本轮将它编入起点 45 所属的 30–50 档，仍完整显示 45–65 dB，并在搜索旁说明规则。该编排不表示整段范围均属于“安静”，也不构成舒适度或健康等级。

搜索 `60` 时，洗碗机仍可在 30–50 组出现，干衣机与交谈在 50–70 组出现，三项都按原始范围匹配；`60 dBA` 只保留交谈。没有混同或换算 dB 与 dBA。

## 标签与体感说明调整复核

本轮保留七档实色、分组和搜索，取消声音摘要的等宽两列。标签由名称、完整分贝范围、来源单位和展开图标决定宽度，超过可用宽度时自然换行。展开后，条件与来源在所选标签下方另起一整行；后续标签自然顺延。原生 `details` 的同组 `name` 使每档一次展开一项，Enter 和空格继续可用，不新增选择状态、尺寸监听或第三方依赖。

展开布局使用 `::details-content` 与 `display: contents` 将说明纳入分组的 Flex 换行。通过 `@supports` 保留旧浏览器降级：不支持该伪元素时，所选条目独占一行，说明仍以原生详情显示，不遮挡其他标签。现代浏览器兼容依据见 [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::details-content)；Safari 与旧浏览器尚未实机验证。

参考竞品的“短名称 + 一句说明”层级，为每档补充声音存在感、交谈是否费力或压迫感等描述。这些文案是大致听感说明，未照搬竞品的疼痛或听力损害阈值，也未新增医学结论。七档名称、全部声音的数值、原始单位与来源保持原有口径，说明与声音详情均在构建 HTML 中。
