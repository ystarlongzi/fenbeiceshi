# 语言自动选择与偏好验证

日期：2026-10-22。范围为本地实现、静态构建与内置浏览器验证，尚未部署生产。

## 展示与切换规则

- 无语言前缀的已发布页面按「已保存的手动偏好 → 浏览器语言列表中首个支持的语言 → 简体中文」选择。语言列表为空时读取浏览器单个语言设置，无法匹配时保留简体。
- `zh-Hans`、中国大陆、新加坡与普通 `zh` 对应简体；`zh-Hant`、台湾、香港、澳门对应繁体，文字体系优先于地区；`en` 及其地区变体对应英文。
- 明确的 `/en/`、`/zh-tw/` 链接保留指定语言，不因浏览器或已保存偏好被覆盖，也不会自动覆盖手动偏好。未知路径保持原来的未找到页面。
- 语言引导脚本位于可见内容之前，只在文档加载时执行，用 `location.replace` 进入对应主题，保留其他查询参数与锚点，避免额外增加一条自动跳转历史；缺少对应主题时回到目标语言首页。
- 自动识别不写入手动偏好。用户通过菜单选择任一语言时才保存，包括选择当前项；以后进入无前缀页面优先恢复该选择。不会在测量途中随系统语言或其他标签页变化强制导航。
- 偏好仅以语言标识存入独立键 `fenbeiceshi:language:v1`，不修改主题、报告或录音。清除本站数据后恢复浏览器语言识别。
- 存储受限时显示三语提示，保留错误上下文；当前链接使用 `language` 参数保留本次选择，避免简体选择再次被浏览器语言覆盖。保存成功后清理该临时参数并收起提示。

## 修改入口

- `src/lib/i18n/preference.ts` 与相邻测试：浏览器匹配、偏好写入、当前页面提示状态、选择链接和首屏脚本。
- `src/components/language-switch/`：菜单事件中保存偏好，保留当前主题、查询和锚点；局部客户端提示复用已有语义颜色，手机向上显示，固定 14px。
- `src/components/site-document/index.tsx`：服务端外壳输出首屏脚本，复用现有页面注册生成可用路径。正文、canonical、hreflang 与各语言静态页面保持按 URL 输出。
- `scripts/check-export.ts`：检查每页引导脚本唯一且早于可见内容，并直接执行构建后的脚本，验证三种保存值及无偏好状态下的行为。
- 同步 README、AGENTS、SEO 规划、工程参考、文档索引及三语隐私正文；语言页面与关键词归属未新增，隐私页修改日期更新为本轮日期。

没有新增依赖。沿用 React 最佳实践的首屏初始化、本机存储隔离及事件内写入方式，并按 documentation-update、simplify 复核职责、文档和变更范围。

## 实际浏览器验证

服务为 `http://127.0.0.1:3181`，桌面 1280×720、手机视口 320×740。

- 在分贝对照页手动选择英文，再打开无前缀的 `/knowledge/decibel-chart/?q=60#levels`，恢复至英文对应页，查询与锚点保留。
- 保存英文后打开明确的繁体文章链接，保持繁体。再选择当前的「繁體中文」，重新进入 `/` 后恢复繁体首页，确认选择当前项也会保存。
- 手机菜单展示恢复后的繁体当前项与三种完整名称，保持既有向上展开行为。
- 通过一次性语言链接检查存储提示；提示在亮色简体、暗色英文下均完整可见。320px 英文提示宽 208px、字号 14px，左右范围 x=92–300，无裁切。
- 在提示状态下以 Home、Enter 选择当前简体，保存成功后临时参数与提示均清除；刷新后继续显示简体。手机主题随后恢复亮色，浏览器视口覆盖已重置。

## 验证边界

不同浏览器语言列表、非法偏好及实际存储异常通过 Node VM 和状态测试覆盖；本轮没有修改真实浏览器语言配置或禁用真实存储。浏览器中的失败提示使用一次性语言链接触发，不能视为真实浏览器存储阻断实测。未验证真实手机、禁用 JavaScript 的浏览器会话、生产响应或搜索引擎抓取；静态正文和 SEO 由产物检查覆盖。麦克风、录音和报告算法未改动，也未重新实测。
