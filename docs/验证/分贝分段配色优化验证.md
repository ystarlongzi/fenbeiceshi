# 分贝分段配色优化验证

日期：2026-10-20。范围为中英分贝对照页的七档概览及共用颜色的数值探索结果、记录量级标签；仅在本地实现与验证，没有部署生产。

## 审查结论与设计判断

用户在这个区域浏览并比较声音量级，再选择分段查询。核心内容是数值、名称与声音示例，分段说明提供必要的来源和理解边界。七行是同级、按量级递进的选择对象，现有顺序、对齐和手机重排适合这个任务，无需新增容器或重排内容。

- `src/app/globals.css:40`：原 85–100 为浅米橙，100–120 和 120+ 都偏粉，七档的表面强调程度接近。高声级改用明确橙色、朱红和深红，后两档搭配浅字，形成不同视觉分量。
- `src/app/globals.css:32`：0–30 使用翠绿、30–50 使用叶绿，均搭配深绿文字；缩小原深底与浅底的明度差，第二档减少黄色感，数值与名称继续说明分段顺序。
- `src/app/globals.css:36`：原 50–70 的蓝色打断绿至暖色的顺序。前三档统一为翠绿、叶绿、饱满黄绿，50–70 减少浅白感，70–85 改为金黄，构成连续的冷暖递进。
- `src/features/decibel-chart/sound-overview/index.module.css:14`：沿用整行背景及数值、名称、示例，不增加侧边色线或装饰图标。悬停与选中继续使用文字色内描边，选中同时有勾选标记和 `aria-pressed`；全局键盘焦点保留独立外轮廓。

这里表示产品的声音量级参考，七档不是国家或国际标准规定的安全等级。没有增加“安全”“危险”或“超标”结论，也没有改动数值边界、名称、来源或健康正文。
