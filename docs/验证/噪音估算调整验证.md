# 噪音估算调整验证

日期：2026-10-18。范围为默认噪音估算、统一口径、输入信号、可选校准、记录兼容与双语内容；未部署生产。实现约定见 [噪音估算口径](../产品/噪音估算口径.md)。

## 实现与职责

- 原始采集与能量统计保留 dBFS，新增 `readings.ts` 统一投影为估算噪音分贝，主仪表、色带、趋势和统计消费同一帧。新记录与导出复用同一转换函数；没有为每种仪表建立独立估算。
- 麦克风旁新增独立 `input-signal` 组件和相邻 CSS Modules，五根小柱使用原始输入幅度，文字区分未采集、采集中、过载与演示。没有新增定时器或第二次采集。
- 参考校准默认收起，成功后替换通用偏移，清除或失配后恢复通用估算；结束结果仍保留当时口径。
- 记录封装版本升为 2，继续读取版本 1。读取不自动重写；旧相对记录保留原单位；同输入、同模型、同偏移才可比较。导出 v2 保留模型与计算下限，不包含内部设备签名或音频。
- 手机检查发现原 SVG 坐标会被整体缩小，改用固定字号 HTML 坐标与独立缩放曲线；坐标和路径仍使用同一 0–120 估算轴。
- 同步中英首页、指南、校准、准确性、dBFS/SPL、量表、麦克风帮助、关于与隐私说明；更新 SEO 摘要、规划、关键词说明、AGENTS、设计层级与当前规格。没有新增 URL 或依赖。

## 工程检查

最终 `npm run check` 退出 0：format:check、ESLint（0 警告）、strict 类型、27 项测试、8 个双语正文、静态构建和产物检查全部通过。产物仍为 22 个页面、20 个 sitemap URL、448 条内部链接与锚点。

新增 5 项测试，另扩展原有采集与记录测试，覆盖：

- 受控采样经生产采集代码得到原始电平，再统一投影为通用估算；仪表输入、趋势及统计数值一致，原始信号不被修改。
- 参考偏移替换通用偏移，清除参考恢复通用估算；能量均值先计算再转换，不直接平均分贝；超出显示刻度的数字不截断。
- 零输入的计算下限、空统计、非法数值、信号柱缺失/低输入/满幅边界。
- 版本 1 只读不改写，首次写入版本 2 保留旧记录；新模型元信息和下限标志进入导出；未知模型与版本拒绝，配额失败不覆盖数据。
- 旧相对、新通用及参考估算不混比；相同输入、相同参考偏移的历史参考记录仍可比较；导出无内部设备签名。

另运行 `git diff --check`、修改文件 JSON 解析、相对文档链接与有效代码行数检查，均通过。既有 npm 用户配置 `home` 提示未在本轮修改。

## 未验证与限制

通用 `+100` 映射是未经跨设备声学验证的产品假设，当前没有量化准确度结论。测试验证计算与口径一致性，不代表真实噪音值准确。

未验证真实麦克风、参考声级计、实机 Safari/Android、原生全屏、生产服务器、Cloudflare 或远程 CI；参考切换与存储升级由受控测试覆盖，浏览器只检查演示与记录空态。没有用演示创建真实记录或实际下载测量文件。
