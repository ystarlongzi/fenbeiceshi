# 吵闹程度名称统一验证

日期：2026-10-20。范围为仪表刻度、中英分贝对照页、数值探索结果、记录页及首页紧凑记录标签；本地实现，未部署生产。

## 当前任务与设计判断

用户在不同位置理解同一读数，名称需要一致且易懂。七档概览和记录标签是同级的量级描述，仪表保留原有六个刻度位置，不新增容器或改变分段。主要问题是仪表文案与共享分段分别维护，以及最高档名称变长后在窄屏挤压相邻刻度。

| 分段    | 中文     | 英文            |
| ------- | -------- | --------------- |
| 0–30    | 非常安静 | Very quiet      |
| 30–50   | 安静     | Quiet           |
| 50–70   | 适中     | Moderate        |
| 70–85   | 较吵     | Fairly noisy    |
| 85–100  | 很吵     | Very noisy      |
| 100–120 | 极吵     | Extremely noisy |
| 120+    | 极强噪音 | Extreme noise   |

分段边界沿用原实现，交界值归入后一档；70 为较吵、85 为很吵、100 为极吵、120 为极强噪音。仪表仍显示 0、40、70、85、100、120，没有 50 这个刻度，因而刻度行不单列“适中”。名称是大致吵闹程度描述，原有非舒适度或安全判定说明保留。

## 文件职责

- `src/lib/content/sound-bands.ts`：唯一的中英文分段名称来源，保留原边界、色彩标识和示例。
- `src/features/sound-meter/copy.ts`：按 `NOISE_SCALE_TICKS` 从共享分段派生中英文刻度名称，不再维护第二套名称数组；沿用现有刻度常量和读取方式。
- `src/features/sound-meter/level-scale/index.module.css`：窄容器的中文末档错开一行；英文偶数项为两行文字留出空间，保留数字线性位置、字号和现有布局。
- `src/lib/content/decibel-chart.ts`：模块标题改为“从安静到吵闹”，同步英文和既有分段说明，实际内容更新日期为 2026-10-20。
- `src/features/sound-meter/copy.test.ts`：验证七档中英文命名，以及六个刻度与同读数记录标签的一致性。
- AGENTS、文档索引、分段配色 V3：更新共享名称入口；原配色验证截图保留，当前名称以本文及 `design/decibel-chart-v3/names/` 为准。

本次提交包含刻度常量提取及其组件引用，使名称能按原有位置派生；知识页层级和录音功能由其他改动维护。连续数字配色、已确认背景、存储和测量口径不变。
