# 仪表与记录七档配色统一验证

日期：2026-10-20。范围为仪表、参考色带、统计卡片、趋势图和记录数字的七档颜色；本轮只验证本地实现，未部署生产。

## 调整结果与文件职责

当前任务是让同一读数在不同模块表达同一档位，保留测量为主要任务、统计为同级摘要、趋势为补充观察的层级。沿用现有布局和中性卡片，不新增容器；只在数字、量级图形及统计顶部细线上表达声音强弱。

- `src/lib/content/sound-bands.ts`：复用已有七档边界，增加共享的 `readingBand`。按界面显示的一位小数判档，避免显示值与标签颜色跨档。
- `src/features/sound-meter/palette.ts`：集中派生七档颜色、真实比例的渐变色点和读数位置，替代原五色连续插值；不另存 React 状态或增加 Effect。
- `src/app/globals.css`：维护深绿仪表使用的亮色及浅底使用的深色文字变量。暗色主题的文字变量引用同档亮色；既有标签背景与标签文字配对保持原值。
- `src/features/sound-meter/meter-display/`、`level-scale/`：弧线、条形、读数及参考色带共用分段。仪表仍为 0–120，120+ 只占终点，通过末端圆点和条形最后一格表达，不人为给它分配区间宽度。六个底部刻度仍为 0、40、70、85、100、120，刻度名称与文字样式沿用既有实现。
- `src/features/sound-meter/session-stats/`：最低、最高、平均分别根据自己的数值与输入下限状态取色。数字使用主题文字色，顶部细线使用亮色；卡片底色与时长卡片保持中性。
- `src/features/sound-meter/sound-trend/index.tsx`：趋势线与当前末端点使用同档主题文字色；70/85 参考虚线保留原状态色。低于输入下限时当前末端点回退中性，历史曲线仍按数值位置着色。
- `src/features/records/`：记录数字使用共享文字色，标签继续使用既有七档背景/文字配对。历史相对电平和低于输入下限的读数保留中性。
- `src/features/sound-meter/palette.test.ts`：覆盖跨模块归档、分段稳定色、非法值与中性状态、真实比例以及显示值舍入后的终点行为。

颜色、边界与角色见 [七档量级颜色规格](../../design/noise-color-v1/design-spec.json)。估算算法、单位、保存与导出格式、录音和麦克风原始信号柱均未修改；正式的 `use-sound-meter.ts` 没有改动，没有加入演示参数或测试路由。没有新增依赖。

## 实际浏览器检查

使用 Codex In-app Browser 检查构建后的正式本地页面 `http://127.0.0.1:3100/`。固定数值在临时应用副本的原生演示中验证，使用独立端口 3106，保留演示标记和禁止保存/导出；记录样本只写入 3106 的隔离存储，未写入或清除 3100 的记录。检查后恢复临时环境为空记录、亮色主题，关闭测试页、停止服务并删除临时副本；正式页面保留演示预览，浏览器视口已恢复默认。

## 颜色对比度

按实际 CSS 色值计算 sRGB 相对亮度；结果见 [contrast-checks.json](../../design/noise-color-v1/contrast-checks.json)。

| 本轮颜色用途             | 检查背景                             | 七档最低对比度 |
| ------------------------ | ------------------------------------ | -------------- |
| 浅色主题数字与趋势       | 白色卡片、斑马纹、选中与悬停底色     | 4.558:1        |
| 暗色主题大数字与图形     | 卡片、斑马纹、选中与悬停底色         | 3.769:1        |
| 深绿仪表大数字与量级图形 | 固定深绿渐变的上、中、下三处背景锚点 | 3.200:1        |

统计/记录数字为 24/25px，仪表读数为 72px 及以上；深底检查采用大文字与图形的 3:1 目标，浅底数字达到 4.5:1。此处不代表对整页所有小字号文字完成了新的对比度审计；12px 标签继续使用既有独立背景和文字配对。
