# 移动端导航抽屉验证

日期：2026-10-20。范围：全站中英文移动导航，本地静态产物与实际浏览器视口；尚未部署生产。

2026-10-22 主题入口已移到页头菜单按钮左侧，抽屉仅保留导航与语言；语言说明和选择框改为同一行。当前布局和主题三态验证见 [三态主题与移动页头验证](./三态主题与移动页头验证.md)，下文保留历史实施记录。

## 任务与层级

手机原页头将四项导航排成第二行，占用约 132px。改为 68px 单行页头，保留品牌与右上角菜单按钮；页面正文和测量入口随之提前。五项同级导航位于右侧抽屉上方，主题与语言切换固定在独立的底部辅助区域；导航占据剩余空间并可单独滚动，底部操作不随导航滚动。抽屉表面及遮罩表达临时导航与背景页面的关系。

- `src/components/site-document/site-navigation/` 管理横向导航、手机抽屉、关闭与焦点、滚动锁定及局部 CSS Modules。
- `src/components/theme-switch/index.module.css` 通过局部 CSS 变量支持底部主题提示向上展示，窄屏提示宽度受限于面板。
- `src/components/site-document/index.tsx` 保持服务端组件，传入导航所需字段及已有主题／语言组件；相邻样式只保留外壳、品牌、语言按钮与页脚职责。
- `src/components/icon/index.tsx` 和 `public/icons.svg` 新增固定来源 Lucide 菜单图标；原始 SVG、提交与许可证在 `design/mobile-navigation-v1/icons/`。
- `scripts/check-export.ts` 对 24 个中英页面验证桌面及抽屉导航完整、当前项一致、菜单默认关闭、按钮与原生 dialog 关联及语言入口静态存在。

未新增依赖或路由。沿用 React 性能技能的局部客户端边界，抽屉采用原生 dialog 与 CSS 动效；参考 transitions-dev 的面板开关时长和减少动画规则。按 simplify 复核职责、复用与事件处理，按 documentation-update 更新规格、项目入口和验证说明。

## 抽屉宽度复核

移动抽屉上限由 340px 调整为 280px，同时至少保留 72px 左侧遮罩。宽度与底部主题提示共用局部 CSS 变量，提示宽度随面板收窄；字体、导航顺序和底部固定操作沿用已有设计。

- 390 × 844 中文：实际宽 280px，左侧保留 110px；全部导航文字完整，底部区域下边缘仍为 820px；遮罩关闭恢复按钮焦点。
- 320 × 360 英文暗色：实际宽 248px，左侧保留 72px；导航文字未横向溢出，上方导航可滚动，底部区域下边缘保持 336px。
- 语言跳转、主题切换及 Esc 关闭均可用；关闭后恢复背景滚动与菜单按钮焦点，验证结束恢复亮色与默认视口。已更新中文、英文暗色及短屏截图。
- 本轮执行定向 Prettier 检查、`npm run build`（含类型检查）与 `npm run test:export`，全部通过；静态产物为 24 页、22 个 sitemap URL、728 条内部链接与锚点。上方全量 `npm run check` 记录对应导航及底部布局交付，本次样式收窄未重复该全量流程。
