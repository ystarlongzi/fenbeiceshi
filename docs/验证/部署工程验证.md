## 主机公钥预置改为可选（2026-10-24）

[首次远端运行](https://github.com/ystarlongzi/fenbeiceshi/actions/runs/40095462255) 的完整检查、Linux 发布/回滚演练和打包均通过，但凭据准备步骤误将 SSH_KNOWN_HOSTS 列为必填，因此在连接服务器之前停止。

发布与回滚工作流现仅要求 SSH_HOST、SSH_USER 和 SSH_PRIVATE_KEY。SSH_KNOWN_HOSTS 省略时不生成主机公钥文件，底层 SSH 继续使用 accept-new；提供时仍生成文件并严格核验。本机模板的 SSH_KNOWN_HOSTS_FILE 默认留空，与工作流行为一致，已有主机公钥记录不匹配时仍会拒绝连接。

本次实际执行：

- `npm run test:deploy`：27 项通过、0 失败；三个独立 Linux 用例按入口约定跳过。
- ESLint 检查本次三个测试文件：零警告通过。
- actionlint 检查三份工作流及内嵌 Shell：通过。

回归同时执行发布与回滚的真实凭据准备脚本，覆盖主机公钥省略/提供、私钥换行及登录凭据缺失；SSH 调用测试验证 accept-new 和严格核验两条分支。服务器脚本、应用代码与依赖未变化，本轮本地未重复构建应用或执行 Linux 集成；后续推送的工作流会继续执行完整检查与部署相关的 Linux 演练。此修正不增加对生产发布完成或真实设备验收的声明。
