# 其他页面搜索文案调整验证

日期：2026-10-25。

## 调整范围

在首页三语确认稿基础上，调整其余 46 个已实现主题的标题与描述，共 138 个非首页 URL。其中 45 个主题可索引，本机记录的三个语言页面继续 noindex，不进入 sitemap。关键词保存在 [页面与关键词映射](../产品/页面与关键词映射.json)，用于明确页面意图和自然表达，不生成 meta keywords，也不新增近义词落地页。

文案先回答用户的问题，说明页面能提供什么；描述补足真实用途，不按固定字数堆词。英文围绕相应意图使用 decibel meter、sound level、noise reduction 等表达，繁体沿用台湾常用词。首页标题、描述、H1 和关键词保持此前确认版本。

| 页面范围                                     | 搜索意图与表达                                           |
| -------------------------------------------- | -------------------------------------------------------- |

声音详情标题去掉“历史测距参考”“观察位置”等生硬短语，改为具体声音名称。描述复用正文的直观结论，避免重复罗列文章栏目；原始测距、历史资料、dB／dBA 区别和健康条件继续完整保留在正文。文章 H1、站内文章名称、Article 与面包屑由现有数据统一派生，知识目录、声音详情和记录页的专属 H1 沿用现有结构。

本轮没有增加依赖、客户端脚本、路由或界面容器。各页自 canonical、三语互返 hreflang、索引策略及静态正文沿用现有实现。候选路由和关键词的搜索量、难度、排名效果没有在本轮验证，不改变其候选状态。

## 实现入口

- `src/lib/content/`：帮助、知识文章、对照表及声音详情元数据；声音详情共用 `decibel-details/index.ts` 的描述生成。
- `src/lib/routing/pages.ts`：首页、知识目录、本机记录与发布注册。
- `src/lib/seo/metadata.ts`：统一派生标题、描述、Open Graph、canonical 与 hreflang；首页按确认稿使用品牌分隔符。
- `src/components/home-page/index.tsx`：首页 WebApplication 描述与首页元数据共用内容。
- `docs/产品/页面与关键词映射.json`：同步已实现主题的三语标题、H1、描述与关键词；记录页在功能路由中记录文案，不分配公开搜索词。

## 发布与边界

推送 `main` 会触发既有生产发布工作流，沿用检查、静态构建、SSH 传输、切版与健康检查流程。没有修改部署配置、Secrets、数据库或浏览器存储格式。推送同时包含原有未推送提交 `fb2c6e5`，其变更为测量状态文案与圆点动效；本轮新增提交只包含 SEO 文案及相应文档。

本机不运行真实 Linux/Nginx/TLS 集成演练；本轮文案不涉及麦克风、录音、保存及导出逻辑，因此不重新申请真实麦克风或把页面渲染检查描述为真实设备测量验收。搜索引擎需要重新抓取后才可能更新结果，实际摘要也可能由搜索引擎重写。
