# 三态主题与移动页头验证

日期：2026-10-22。范围为本地三语站点主题菜单、手机页头与相邻导航操作，尚未部署生产。

## 行为与职责

- 主题入口保持紧凑图标，展开后显示「跟随系统、深色、浅色」三个同级选项。英文为 System、Dark、Light，繁体为「跟隨系統、深色、淺色」。显示器、月亮、太阳对应所选模式，当前项带勾选。
- `src/components/theme-switch/` 管主题选择、键盘操作、外部点击关闭与局部样式。选择模式与实际外观分开读取，避免把系统当前显示的浅色误认为用户选了浅色。
- 继续使用 `fenbeiceshi:theme:v1`，接受 `system`、`dark`、`light`；旧值无需迁移。默认跟随系统，主动选择跟随系统后立即恢复联动并可持久化。深色、浅色不受系统变化覆盖；同源标签页同步选择。
- 首屏主题脚本继续在可见内容前应用偏好，按钮图标通过根节点偏好显示。正文及外壳保持服务端渲染，主题选项静态输出，交互绑定前按钮禁用。
- `src/components/site-document/site-navigation/` 将手机主题按钮与菜单按钮合组，主题在左、菜单在右；两者均为 44px，间距 8px。桌面主题入口为 36px。断点继续使用 760px。
- 抽屉保留六项导航及语言切换，语言说明与控件同一行、选择框靠右，语言列表继续向上展开。移除只服务于原抽屉主题提示的 CSS 变量。
- 菜单支持方向键循环、Home / End、Enter / 空格确认、Esc 收起、Tab 离开，失焦和点击外部关闭；打开手机导航会收起主题列表。
- 沿用既有语义配色与固定字号：主题选项 12px，存储异常提示 14px。没有新增依赖；显示器图标从现有 Lucide 固定提交取得，SVG、来源及许可证入口位于 `design/theme-v2/icons/`。
- 同步 [主题 V2 规格](../../design/theme-v2/design-spec.json)、AGENTS、README、三语隐私正文、文档索引与历史验证入口。沿用 React 最佳实践、documentation-update、simplify，复核了局部客户端边界及样式职责。

- `rtk npm run check` 全部通过：format:check、lint、strict 类型、123 项测试、三语内容、静态构建及产物检查。
- 主题的 8 项测试覆盖首屏偏好、非法值、存储异常、系统变化、手动固定外观、跨标签页事件与取消订阅。新增两项验证主动回到 System 后的持续联动、刷新恢复，以及保存失败时仍跟随本次系统变化。

## 实际浏览器检查

开发服务：`http://127.0.0.1:3181`。内置浏览器覆盖 1280×720、761×800 桌面，320×740 手机和 320×360 英文短屏。

- 确认用户所指 `index-module__UGfLxG__trigger` 为手机菜单按钮，主题与它位于同一页头组。320px 下主题范围 x=208–252，菜单 x=260–304，高度均为 44px；页面宽与 scrollWidth 均为 320px。
- 选择深色后刷新，页面及当前项继续为深色；用 Home、Enter 选择跟随系统后刷新，保持 `system`，本机当前实际外观为浅色。
- Home 与 ArrowUp 循环到浅色；Esc 收起并保留主题按钮焦点；空格打开后按 Tab 到达菜单按钮。主题列表打开时点击菜单，主题收起且导航正常打开。
- 抽屉中没有主题选择框，语言选择保持可用；英文短屏语言弹层范围 x=148–300、y=160–290，未被抽屉裁切。关闭后焦点及背景滚动恢复。
- 繁体标签页依次选择深色、淺色、跟隨系統，原简体标签页同步为 dark、light、system；最终恢复跟随系统。
- 英文短屏完整显示 System、Dark、Light，列表范围 x=76–252、y=62–192；761px 桌面页面宽与 scrollWidth 均为 761px。主题展开时切到桌面宽度，两个主题入口均恢复收起状态。
- 浏览器视口覆盖已重置。主题选择测试仅操作本机偏好，没有开始测量或改写报告。
