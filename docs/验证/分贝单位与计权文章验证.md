# 分贝单位与计权文章验证

日期：2026-11-23。本批为本地实现，尚未部署。新增主题 `db-dba` 使用规划中的 `/knowledge/db-vs-dba/`；简体、繁体、英文及既有 24 种国际语言均有静态正文。

## 任务与归属

文章帮助普通读者理解分贝标记并判断读数能否比较。先解释 dB 的含义，再用同级对照表解释 A／C／Z；固定换算的限制就近说明，B／D／G 为后续补充，SPL／FS 用另一张表区分参考基准，最后说明本站估算。正文连续阅读，使用现有文章模板、目录和表格，没有新增卡片、筛选器或测量控件。简繁目录用短标题适配手机，正文使用完整问题。

现有 dBFS／SPL 文章继续承担数字输入、估算公式和声压对应关系的技术解释；本页只给入门定义并链接该文章。声音量级和具体例子继续由分贝对照页及既有详情页承接；主操作进入分贝对照表。没有为 A、C、Z 或同义词分别建立页面。

既有 Bing 基线中的宽泛词“分贝”为三个月约 5.7K 印象，“db”查询有歧义。本批依照已有需求方向和用户确认的解释范围落地；未新增 dBA／dBC／dBZ 专门关键词研究，也不把宽泛词数据当作本页搜索量或流量预测。原始筛选条件见 [中文页面优先级](../产品/Bing中文页面SEO优化优先级.md)。

## 内容与来源

- [NPL · 声压级与声强级](https://resource.npl.co.uk/acoustics/techguides/concepts/spl.html)：声压参考量及空气声的 20 µPa；对数刻度与主观响度的区别另参照 [UNSW · Decibels](https://www.animations.physics.unsw.edu.au/jw/dB.htm)。页面不把数字翻倍解释为听感翻倍。
- [Cirrus Research · A/C/Z](https://cirrusresearch.com/what-are-a-c-z-frequency-weightings/)：常见计权的形状与用途。A 只近似考虑听觉频率敏感度；C 常见于峰值测量；Z 的平直响应限于规定频带，不解释成任意设备的全频率完美测量。
- [NTi Audio · 频率计权及修正表](https://www.nti-audio.com/en/support/know-how/frequency-weightings-for-sound-level-measurements)：1000 Hz 的 A／Z 标称修正均为 0 dB，63 Hz 的 A 为 −26.2 dB、Z 为 0 dB。例子明确是单频滤波修正量，不是实际房间测量；混合声音没有通用固定换算差值。
- [Massport · 历史噪音技术附录](https://www.massport.com/sites/default/files/2023-10/ea_deir_cd-version_volume-ii.pdf)：B 计权的历史与较少使用背景，不据此推广该报告的法律或仪器规定。
- [IEC 60537:1976](https://webstore.iec.ch/en/publication/16531)：D 计权用于飞机噪音测量，对应标准已于 2016-11-19 撤销。正文仅保留历史用途，未把它写作现行航空评价的一般要求。
- [ISO 7196:1995](https://www.iso.org/standard/13813.html)：G 计权的次声测量范围。只用于解释术语，不推导个人风险或把 G 与 A 的总值直接比较。
- [MDN · Web Audio API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API) 及本站 `readings.ts`、`capture.ts`：数字输入与空气声压需要区分。本站没有经声学精度验证的 A／C／Z 测量能力；不施加 A／C 滤波不能证明整条输入链具有合格的 Z 响应，手动偏移也不能补偿频率响应。

## 实现与发布范围

- `src/lib/content/decibel-units.ts` 维护三种基础语言正文、两张表、来源、关联文章及主操作文案。文章注册、metadata、Article／BreadcrumbList、自 canonical、27 语互返 hreflang 与 sitemap 沿用现有派生机制。
- `src/features/decibel-units/` 复用 `ContentPage`，为新主题选择分贝对照主操作，并通过章节 Props 与 CSS 变量让两列表格在窄屏内换行；第一列保持完整技术标记，解释列自然换行，固定 14px。共享表格仅增加可选最小宽度变量，其他文章保留 470px 默认值。知识目录的“理解读数”新增入口，准确性文章、dBFS／SPL 文章和分贝对照页在既有继续阅读区提供返回入口。首页内容与精选文章列表没有改动。
- 24 种国际语言各增加 36 条 `knowledge.json` 文案，不添加运行时翻译、英文回退、依赖或客户端正文。共同技术标记保持原符号；阿拉伯语新正文中的参考声压和滤波修正量采用 Unicode 方向隔离，保证数值、负号与单位按从左到右阅读。正文语义、术语和数值进行定向复核；未逐一由母语编辑或声学专家审校。
- 本地主题从 47 增至 48，27 种语言共 1296 个 URL：中文 96、国际 1200；1269 个可索引、27 个记录页 noindex。sitemap 中文 94、国际 1175。英文兼容映射从 94 增至 96 条；未知路径仍保持 404。本批不把本地构建的映射记为生产 Nginx 已更新。
- 同步关键词映射中的候选状态、真实主题清单、基础语言 metadata、相关目标、文档索引、当前工程数量和项目规则；历史批次验证记录保留原始数量。
