## 实现范围

- `deploy/indexnow.mjs` 提供准备、自动通知、预演与少量 URL 的定向补提；`deploy/indexnow/` 分开维护正文清单、协议与重试、服务器状态。仅复用 Node 内置模块、既有 SSH 与 Linux 工具，没有新增或升级依赖、改变网页正文、测量算法或浏览器数据。
- 构建为各域生成公开正文指纹清单；导出检查重新比对。通知不跟随构建资源哈希或 RSC 改变，首次只建立基线；后续比较最近确认状态，发送新增、修改、删除或转为 noindex 的变化。27 个本机记录页不进入初始清单。
- 工作流在所有权文件准备后打包，先英文后中文发布；双站健康检查通过后才通知。稳定密钥保存在各站服务器目录，公开验证文件按协议随版本发布；结果不含密钥，失败保留可重试状态。200 与 202 分别记录，均不记作收录成功。
- 操作、故障处理与回滚边界见 [IndexNow 部署说明](../部署/IndexNow.md)。采用内置 fetch、crypto 和已有 SSH；第三方 SDK 会增加依赖和运行环境要求，本任务没有需要它补足的能力。只手工点击 Bing 适合单次排查，无法覆盖后续发布变化，因此保留手动补提作为自动流程的补充。
- 已读取 vercel-react-best-practices，使用独立请求及清单批次内的并行读取；网页客户端没有新增模块。完成检查后按 simplify 复核复用、职责与注释。
