# 国旗静态资源缓存验证

日期：2026-10-26。范围为两个站点共用的国旗 SVG、资源版本参数及 Nginx 缓存配置；本轮未操作生产服务器。

## 行为与维护

线上核查时，`https://soundmetergo.com/vendor/flag-icons/4x3/hu.svg` 返回 `Cache-Control: no-cache`，携带 ETag 再次请求返回 304。国旗落入通用 `location /`，此前只有 `/_next/static/` 使用一年强缓存。

本次调整：

- 固定国旗地址使用 `public, max-age=86400`，缓存一天。
- 站内国旗地址附加 `?v=7.6.0`，当前版本使用 `public, max-age=31536000, immutable`，缓存一年。
- 版本常量在 `src/components/language-switch/flags.ts` 维护，由站内引用和 Nginx 模板渲染器共用；资源测试校验其与来源清单的版本一致。
- 缓存规则只匹配本机国旗目录下的两字母 SVG 文件；来源清单、许可证、HTML、哈希资源和发布标记保留各自策略。
- 404 使用显式 `Cache-Control: no-cache` 并保留安全响应头。真实 Nginx 测试确认 `expires -1` 不会为 404 生成缓存头，因此此处使用 `add_header ... always`。

修改文件包括 `flags.ts` 及相邻测试、`deploy/nginx-template.mjs`、Nginx 模板、双站配置测试、真实 Nginx 集成测试，以及工程和部署说明。未新增依赖、客户端请求或组件边界；按 React 性能技能保留静态路径生成，并按 simplify 复核改动范围、版本复用和注释。
