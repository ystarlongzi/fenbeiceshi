# 知识目录帮助卡片验证

日期：2026-10-21。范围为本地 `/knowledge/`、`/en/knowledge/` 页首三个帮助入口及下方四个知识分类模块。

## 任务与实现

原先使用指南、工作原理、常见问题只有名称，用户不容易判断各自能解决什么。三个入口属于同级任务，按用户要求改成三个可独立选择的卡片；下方四组知识目录将分类说明与所属文章归在同一块主题背景里，便于辨认文章归属。

- 每张卡片由图标、20px 标题、14px 用途说明和操作入口组成。补充的说明分别承接操作步骤、估算过程与限制、按问题找答案，中英文同步。
- 860px 以上三列排列，标题、说明和底部入口对齐；860px 及以下单列。680px 及以下收起重复的底部操作文字，在右上角保留箭头，说明完整可见，使下方目录更早出现。
- 整张卡片使用原生 Link，通过标题和说明提供可访问名称与描述；图标为装饰并隐藏于辅助技术。保留键盘、焦点与按压反馈。
- `src/components/knowledge-page/index.tsx` 和相邻 CSS Modules 负责内容与样式。正文、三张卡片及链接均由服务端静态输出，没有新增客户端组件、依赖或全局样式。
- 复用 Lucide 的书本与声波图标，补充问号圆圈到 `src/components/icon/index.tsx`、`public/icons.svg`。新增 SVG 固定到现有图标相同的上游 commit，保留 [来源记录](../../design/knowledge-help-v1/icons/source.json)、原 SVG 和完整 ISC／Feather MIT 许可；[上游文件](https://raw.githubusercontent.com/lucide-icons/lucide/1ef60af944de207e0d5176905a0759ba12e6ee8d/icons/circle-question-mark.svg)。
- 三个目的页、知识文章、页面标题、路由、语言关系与关键词归属未改变；未修改其他页面或测量行为。

## 知识分类模块统一

分类标题与文章原先仅由通栏横线分组，归属较弱。本次只调整知识页相邻 CSS Modules，将每个分类的标题、说明和文章收在同一表面中；文章本身继续使用列表分隔，正文和链接仍为静态输出。

- 四个分类与上方帮助卡片共用主题表面、1px 边框及 12px 圆角；亮色为白底，暗色使用既有深色表面。
- 桌面保持左侧分类、右侧文章两列，通过细竖线区分角色。模块内边距 28px，模块间距 20px；分类标题 24px、文章标题 20px、说明 14px。
- 760px 及以下改为分类、说明、文章上下排列，并使用横向分隔；680px 及以下内边距 20px、模块间距 16px。分类之间的距离与模块内部的文章分隔形成不同层级，窄屏保持字号和完整说明。
- 文章悬停和聚焦改用柔和主题背景，在白色容器中仍可识别操作；没有新增图标、客户端逻辑或依赖。
