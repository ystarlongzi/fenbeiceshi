日期：2026-11-23。范围为简体中文首页的搜索标题、描述和首屏简介，以及对应关键词规划。本轮使用 2026-11-22 实际读取的 Bing 数据。本文记录调整与本地验收，后续生产提交及上线结果见 [中文 SEO 与 Next.js 安全升级上线验证](./中文SEO与Next安全升级上线验证.md)。

## 实现范围

- 搜索标题为“在线分贝测试 - 免费分贝仪网页版，支持手机和电脑 | 分贝测试”，继续由 `src/lib/routing/pages.ts` 和原 metadata 帮助函数生成。
- 描述为“免费分贝仪网页版，手机或电脑打开网页就能在线测分贝，无需下载安装。用麦克风查看估算噪音分贝（dB）与实时趋势，比较房间、家电或周围环境的声音变化，测完可保存记录、导出报告。”同一内容继续用于 meta、Open Graph 和 WebApplication 结构化数据。
- 首屏简介为“免费分贝仪网页版，手机或电脑打开即用。用麦克风查看估算分贝与趋势，保存记录或导出报告。”保留原 H1、测量入口、内容顺序及 CSS Modules，测量仍为首要任务。
- 所有网页版工具近义词归属既有首页；未新增路由、重复工具页、依赖或客户端逻辑。繁体、英文及其他国际语言的文案不变，canonical、hreflang、索引策略和记录行为不变。
- `docs/产品/页面与关键词映射.json` 与整站规划同步记录本轮证据，保留候选状态与实际发布状态的区别。基础单位解释与法规文章补强为后续内容，不计入本轮已实现范围。
- 已按 copy-editing 的局部编辑方式、React 服务端边界、文档维护及 simplify 技能复核职责和改动范围，继续复用现有元数据与服务端文案，未引入额外实现。

## 实际验证

- 首次 `npm run check` 中，format:check、lint、strict 类型检查、应用测试、test:deploy 和 test:content 均通过；部署测试 31 项通过，4 项 Linux／Nginx／TLS 集成测试跳过。整条命令在构建阶段被 Next.js 的安全版本提醒中断，退出码 1，不记为完整 check 通过。
- `npm run build` 的英文子构建完成。中文构建被相同提醒中断后，单独执行 `NEXT_PUBLIC_SITE_TARGET=fenbeiceshi node node_modules/next/dist/bin/next build --webpack`，按提示重试后退出码 0；没有修改 Next.js 配置或依赖。随后按 `scripts/build-sites.mjs` 的中文分支移除额外生成的 24 个国际语言目录，并写入中文 `_site.txt` 标记。
- `npm run test:export`：退出码 0。中文 94 页、92 个 sitemap URL、3696 条内部链接与锚点通过；英文基础 47 页、国际站 1150 个 sitemap URL、3963 条基础内部链接与锚点通过；新增语言 1128 页、95112 条内部链接与锚点通过。两域合计 1269 页、1242 个 sitemap URL。
- `node artifacts/seo-bing/check-home.mjs`：退出码 0。简体、繁体和英文首页均只有一份 title 与 description；meta、Open Graph、WebApplication 描述一致，H1、自 canonical、27 种语言与 x-default 共 28 项对应关系正确。简体简介存在于静态正文，繁体和英文首页保持原文案。结果保存在 `artifacts/seo-bing/rendered-metadata.json`。
- 关键词规划专项 Node 检查：仅简体首页条目及证据说明更新，其他页面、繁体／英文首页和候选状态与原版本一致，关键词没有重复。
- 实际浏览器检查：简体首页覆盖 1280 × 720 桌面、375 × 812 和 320 × 740 手机视口；页面宽度均等于视口宽度，简介保持 16px。两种手机尺寸的“开始测量”按钮均完整位于首屏；移动菜单可打开并用 Esc 关闭，桌面准确性帮助链接可进入对应文章并返回首页。临时视口覆盖已清除。
- 本地截图为 `artifacts/seo-bing/after-desktop.jpg`、`after-mobile-375.jpg` 和 `after-mobile-320.jpg`，浏览器测量结果在同目录的 `browser-checks.json`。截图验证排版，不代替真实麦克风测试。
- 最终 `npm run format:check` 与 `git diff --check`：退出码 0。命令仍出现既有 npm `home` 配置警告，本轮没有更改用户 npm 配置。

## 后续观察与验证边界

正式发布后以发布日期为起点，观察 2–4 周的关键词展示、平均排名及相近排名下的点击率；保留以上基线，不能仅凭点击率变化判断标题效果。搜索引擎可能重写或截断标题和摘要，本地静态产物通过不表示搜索结果已更新。

上述本地阶段未执行生产部署、站长平台提交或排名效果验收，也未验证真实麦克风、真实移动设备与声学精度；后续发布另见上线记录。Bing 需求与表现的口径参见 [关键词研究说明](https://www.bing.com/webmasters/help/keyword-research-628070b6) 和 [搜索性能说明](https://www.bing.com/webmasters/help/search-performance-c680da36)。

本轮 SEO 验证使用 Next.js 16.4.2，构建时提示存在已知安全漏洞；当时按框架提供的重试流程完成构建，没有把重试视为漏洞修复。后续已单独升级至 16.4.6，审计、构建和验证结果见 [Next.js 安全升级验证](./Next.js安全升级验证.md)。
