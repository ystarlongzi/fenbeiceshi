## 测试覆盖的具体行为

- 数字采样 RMS、零输入显示下限、满幅正弦约 -3.0103 dBFS、按能量求均值；非法输入被拒绝，刻度按数值比例分配。
- 参考校准的输入边界与设备签名匹配；参考关系不跨输入沿用。
- 记录格式损坏、错误版本、重复、超量、非法数值及演示伪装被拒绝；存储配额失败保留旧数据，存储恢复后可再次保存。
- JSON 导出移除内部输入标识，保留口径和条件；仅同输入与同偏移口径可比较。
- 通过模拟 `MediaStream`、`AudioContext` 和帧调度执行实际采集类：计算电平、停止释放资源、恢复等待期间取消、设备结束中断。
- 授权等待取消后迟到的音轨立即停止；拒绝保留原错误；已取消的会话不再次发起麦克风请求。

这些是信号、存储和生命周期测试，不等于真实声学准确度或所有浏览器权限分支已实测。

## 已知依赖问题

完整审计的 5 个 high 条目来自 `eslint-config-next → @next/eslint-plugin-next → fast-glob → micromatch → braces@3.0.3`。根问题为 [GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)，深层 glob 模式可导致栈耗尽；核对时没有官方已发布补丁。

该链用于开发与 CI 检查，不进入静态浏览器产物；本站也未提供访客 glob 输入接口。npm 的自动建议是将 Next.js ESLint 配套回退到 14.2.35，本次未做跨主版本降级或未经验证的 override。后续应在上游补丁发布后评估升级，开发链告警仍然保留。完整选型依据和安装警告见 [依赖与检查配置](../开发/依赖与检查配置.md)。
