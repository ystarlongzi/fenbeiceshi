# 提示、警告与正文区分验证

日期：2026-10-24。范围：本地三语 Web 与共用页面模板，尚未部署生产。

## 排查与调整

| 页面或组件                      | 原有表现                           | 本轮处理                                                   |
| ------------------------------- | ---------------------------------- | ---------------------------------------------------------- |
| 分贝指南职业参考                | 两段说明与正文相近                 | 合为一个琥珀色提示区，保留口径与适用限制的原有 ID          |
| 健康文章时长工具                | 动态建议、限制和输入错误主要靠字色 | 绿色提示、琥珀色范围限制、红色输入错误，输入与结果关联不变 |
| 28 个声音详情主题               | 概览限制与比较条件像普通段落       | 限制用警告区，比较方法用信息区，三语共覆盖 84 页           |
| 测量设置                        | 输入处理警告与修正错误为纯文字     | 就近增加独立提示表面，冻结或不可编辑状态使用信息提示       |
| 录音设置与结果                  | 上限、中断、编码及播放失败只有字色 | 分别采用警告／错误提示，整理和编码进度为信息提示           |
| 报告弹框                        | 音频消息和操作反馈仅用文字颜色     | 补充底色与左侧强调线，保留原有实时区域及空状态隐藏         |
| 主题、语言偏好提示              | 白色浮层与普通菜单表面相近         | 沿用原定位，使用警告色和强调线区分保存失败                 |
| 测量主消息、记录、文章摘要、FAQ | 已有独立背景、边界或状态色         | 复核后保留；不将普通正文、表单标签或来源变成提示框         |

## 实现边界

- `src/components/notice/` 只负责展示，服务端和必要的客户端子树复用，不新增依赖或客户端状态。
- 使用现有语义颜色，信息、警告、错误分别呈现；保留图标和完整文字，不只依赖颜色。关键提示及错误保持 14px，手机不缩小字号。
- 静态内容默认 `role="note"`；原有 `status`、`alert`、`aria-live` 与 `aria-describedby` 继续使用。报告反馈保留原空节点，避免改变通知生命周期。
- 本轮没有修改文案事实、声音数值、路由、SEO、麦克风权限、录音或存储逻辑；原有目录与按钮保持可用。

## 验证

最终 `npm run check` 退出码为 0：格式、零警告 ESLint、strict 类型、144 项测试、44 个三语正文、构建与静态产物检查全部通过；产物为 141 个页面、138 个 sitemap URL、4,947 条内部链接与锚点。输入错误时，字段与结果两处提示均已复核为错误色。

提示区第一次构建在清理旧 `out/` 时出现 `ENOTEMPTY`；将 Git 忽略的旧产物移入系统临时目录保留后重新执行完整检查，构建与产物校验通过。没有删除用户文件或修改检查规则。npm 仍有原有的 `Unknown user/env config "home"` 提示。

## 浏览器与视觉检查

实际使用 Codex 内置 Chromium 检查，原始数据见 [浏览器记录](../../design/notice-v1/browser-checks.json)。

- 桌面 1440px：健康文章正常状态能区分信息与限制；输入 999 后显示独立错误提示，并继续通过 `aria-describedby` 关联输入。测量设置的读数修正越界时显示红色 `status` 提示。
- 手机 390px：设置抽屉内完整显示输入错误，保留 14px，文档宽度等于视口。英文深色健康页的信息与限制提示使用对应主题色。
- 窄屏 320px：英文越界输入的字段与结果提示均为错误色，繁体职业限制完整换行；使用指南、FAQ、记录及知识目录没有横向溢出。
- 10 分贝详情页的概览限制与量级比较说明分别为警告／信息提示；共用模板覆盖 28 个三语主题。
- 实测信息、警告、错误在亮暗主题的文字对比度为 4.80–7.79，字号均为 14px；没有依赖仅改变字色来区分正文。
- 检查后恢复「跟随系统」，清除临时视口，关闭测试页。

## 未验证范围

真实麦克风和手机、录音硬件故障、浏览器存储受限及生产服务器不在本轮实际设备验证范围。对应状态的展示通过共用组件、静态检查与既有生命周期测试覆盖，不能据此声称完成真实设备故障演练。
