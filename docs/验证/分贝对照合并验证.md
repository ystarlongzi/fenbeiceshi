# 分贝对照合并验证

日期：2026-10-20。范围：`/knowledge/decibel-chart/` 与英文对应页；本地实现，尚未部署生产。

## 任务与层级

用户需要浏览声音量级，或输入一个声音／数值找到对应参考。原先七档中的示例与完整声音列表重复，并由“分段概览”和“声音查询”两个章节隔开；类别、独立数值输入和滑块增加了同一任务的入口。

本轮将搜索、七档和结果合为一个“声音分贝对照”区。七档只展示范围与程度名称，具体声音、原始参考范围、比较条件和来源集中在一份列表。默认完整展示 31 项；搜索与分段选择可组合，结果就地变化。读数说明与健康导读继续作为后续阅读内容。

桌面七档并排；1100px 及以下改为四列，520px 及以下改为两列，手机色块内边距收紧。分段范围固定 16px、名称 14px、单位 12px；页面标题仍为 32px，窄屏不缩小字号。

## 实现职责

- `src/lib/content/decibel-chart.ts`：合并两章为“声音对照”，同步双语描述与目录；保留单位、距离和估算差异说明。
- `src/features/decibel-chart/index.tsx`：在单一章节传入当前语言的声音和七档数据，删除整页选择状态包装及重复示例数据。
- `sound-reference-list/`：保存搜索与分段状态，派生匹配列表；移除类别参数，合并结果数量与清除操作，保持 31 项默认静态输出。
- `sound-overview/`：改为受控的紧凑七档选择，不再主动滚动到结果或移动焦点。按钮继续提供 `aria-pressed` 和关联结果区域，数量使用 `status` 宣告。
- `sound-explorer/`：随独立输入与滑块移除；原先仍被健康文章使用的整数解析函数迁入 `noise-health/exposure-explorer/model.ts`，相邻测试覆盖原输入边界。
- `scripts/check-export.ts`：验证单一对照章节、七档关联、每项声音只出现一份、无类别和滑块，以及健康文章入口与静态正文。

组件专属样式保留在相邻 CSS Modules；搜索和分段之外的文章正文保持服务端输出。本轮没有新增依赖。采用既有设计层级、React 最佳实践、文档维护和 simplify 检查，删除不再需要的 Context 与数值选择状态，匹配范围和数量直接从当前输入派生。

## 工程检查

当前工作区同时存在其他仪表、录音设置及导出功能的修改。第一次在工作区执行 `rtk proxy npm run check`，format、lint、typecheck、75 项单测和内容检查通过，但构建报出 `workbench-qa/page.tsx doesn't have a root layout`。没有删除或修改该临时路由及其他任务代码。

为避免同时使用 `.next` 的开发与构建过程互相影响，另以提交 `70f0e9a` 为基线，覆盖本次对照页、健康输入解析、检查脚本和文档，在独立临时副本中链接现有 `node_modules` 完成验证。副本采用基线依赖清单，不包含工作区中其他任务新增的依赖、测试及临时路由。
