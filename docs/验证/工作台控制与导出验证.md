# 工作台控制与导出验证

日期：2026-10-20。范围为控制按钮、右侧设置及保存、导出、全屏的必要联动；仪表、色带、统计、趋势、录音结果区和记录列表的结构及样式不变。录音下载与报告弹框共用编码状态。首页步骤和使用指南仅同步已失效的演示、备注时机及导出说明。

## 交互与职责

- 控制区移除体验演示；等待授权显示取消，测量中显示结束；整理录音期间显示进度。结束后才出现保存、导出。已保存改为状态文字；备注改变后可更新同一条记录。
- 右侧设置依次为麦克风、图文仪表样式、同步录音、可选参考校准。移除“本次条件”及独立隐私模块，录音旁保留本机处理说明。
- 麦克风使用自定义 `combobox/listbox`，保留默认输入，过滤空 ID 与重复设备。支持点击、触屏、方向键、Home/End、键入名称前缀、Enter 选择、Tab/点外部关闭。抽屉内 Escape 优先收起菜单，再次 Escape 关闭抽屉；采集中保持设备锁定。
- 同步录音与参考校准共用 `src/components/switch`，使用原生 checkbox 的键盘和表单语义及 `role="switch"`，自定义轨道与滑块，保留焦点、禁用态、双主题及减少动画规则。两个开关均默认关闭，录音在采集或尾部整理期间锁定。
- 开启参考校准后展开 20–120 dB、0.1 步长的滑块、输入框和来源。仅在真实输入有效、未过载、来源与读数有效时显示应用按钮；点击建立参考关系后才应用，关闭开关清除参考并恢复实时通用估算，设备切换同时关闭开关。桌面与抽屉共享开关和草稿，结束后的结果保留原设备与口径。
- 移除结束后的设置提示、样式切换说明、校准状态标签与原 `details` 折叠入口。校准状态仍由主仪表的当前口径说明。
- 手机（≤760px）设置从控制区打开右侧抽屉；桌面全屏也保留这个入口。使用原生 `dialog` 管理焦点、背景不可操作、Escape、遮罩关闭和返回焦点；Escape 优先关闭弹框。支持减少动画偏好。
- 保存、导出弹框的输入统一标为“备注（选填）”，最多 120 个 UTF-16 单元；两处共用草稿。新测量清空草稿；保存后修改会更新原 ID，不新增重复记录。
- `measurement-report` 管理报告数据、弹框、CSV、Excel 与 PDF；`workbench-dialog` 管理本工作台的弹框和抽屉。继续复用 `publicSummary`、`readings.ts` 与现有本机存储，不新增全站客户端状态或全局样式。

## 导出契约

| 操作     | 实际内容                                                                                                                                                                                                       |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CSV      | UTF-8 BOM、CRLF、固定六列。前两列为摘要项目和值，后四列为趋势时间、读数、单位、输入下限标记；每行六列，便于标准 CSV 解析器读取。引号和换行正确转义，外部文本的公式前缀加单引号保护。                           |
| Excel    | 真正的 `.xlsx` OOXML，摘要及最近趋势两个工作表；数值和布尔值保留单元格类型，普通字符串不成为公式。                                                                                                             |
| PDF      | 真正的 A4 `.pdf`，含口径、单位、时间、统计、设备、模型、参考、备注、最近趋势及限制说明。使用本机字体绘制为约 192 dpi 图像后嵌入；长内容按段落分页。文本不能在 PDF 内搜索或选取，可改用复制摘要、CSV 或 Excel。 |
| 复制摘要 | Clipboard API；被拒绝或不可用时显示只读摘要，获得焦点后可全选手动复制。                                                                                                                                        |
| MP3      | 仅当前测量有录音时显示；点击后本机编码，完成后下载独立 `.mp3` 文件。与原录音区共用任务和结果，失败可重试。                                                                                                     |
| PCM      | 仅当前测量有录音时显示；立即下载独立原始 `.pcm`，单声道、有符号 16 位小端，显示实际采样率，文件名保留参数。                                                                                                    |

读数按现有一位小数展示并导出，下限保留独立标记；模型及其实际偏移保留。历史相对记录继续使用 dBFS RMS，不重新解释为噪音分贝。趋势只包含最近最多 60 秒，不冒充全程曲线。CSV、Excel、PDF 与复制摘要不包含音频和内部设备签名，不标注为 dBA 或专业检测；音频单独下载。记录页下载入口也复用同一报告弹框，替换原先的直接 JSON 下载；弹框内修改的备注仅用于本次导出，不写回已保存的记录，历史摘要不恢复音频入口。

## 依赖评估

仅新增固定版本 `write-excel-file@4.1.1` 和 `jspdf@4.2.1`，不升级既有依赖。CSV、剪贴板、报告绘图使用浏览器现有能力；Excel/PDF 库仅在点击对应操作时动态加载。

| 方案                 | 判断                                                                                                                                             |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 自行生成 ZIP/OOXML   | 可少用一个依赖，但需要维护表格格式、XML、类型及兼容性；选用职责更窄的现成写入库。                                                                |
| ExcelJS / SheetJS    | 更完整的读写、公式及复杂样式能力超出本轮需求，未引入。                                                                                           |
| write-excel-file     | 浏览器及通用入口、TypeScript 类型、支持多工作表与 Blob，直接依赖仅 fflate；采用通用入口处理至多 600 个趋势点，避免 Blob Worker 的额外 CSP 要求。 |
| 浏览器打印           | 不新增依赖，但需要用户再操作打印窗口，不能直接交付下载文件；本轮不采用。                                                                         |
| pdf-lib              | 可生成 PDF，但当前 npm 版本 1.17.1，元数据最近修改为 2023-07；本轮选择有近期安全修复的 jsPDF。                                                   |
| jsPDF + 完整中文字体 | 可提供可选取的文本，但完整 CJK 字库会显著增加下载与字体维护成本；本轮采用本机字体绘图后嵌入 JPEG，明确保留文本选择限制。                         |

核验依据：[write-excel-file 官方仓库与 API](https://github.com/catamphetamine/write-excel-file)、[jsPDF 官方发布记录](https://github.com/parallax/jsPDF/releases)、[4.2.1 修复公告](https://github.com/parallax/jsPDF/security/advisories/GHSA-wfv2-pwc8-crg5) 及安装包元数据、许可证。两项直接依赖均为 MIT；24 个新增包合计安装约 44.4 MB（包括可选包、源码、声明及映射文件，不等于浏览器下载体积）。未调用 jsPDF 的 HTML、SVG 或外部文档读取能力。

新增传递许可包含 MIT、Zlib、DOMPurify 的 MPL-2.0 / Apache-2.0 双选项以及 rgbcolor 的 MIT 选项；完整声明保留在 `public/vendor/report-export/NOTICE.txt`。无新增字体、外部请求或服务端处理。

安全检查：配置镜像的 audit 接口返回 404，改用 npm 官方 registry。`npm audit --omit=dev --registry=https://registry.npmjs.org --json` 返回生产依赖 0 项。全量审计仍报告既有 ESLint → fast-glob → micromatch → braces 链的 5 个高危条目；锁文件中既有依赖版本均未改变，不在本轮盲目降级 Next.js 检查配置。
