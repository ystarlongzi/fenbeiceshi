# 分贝对照页扩充验证

更新：2026-10-18。范围为本地实现与静态预览，尚未部署生产。

## 任务与结果

用户需要快速知道常见声音的大致分贝，并能直接从一级导航进入。此前正文只有三组参考，40–70 分贝章节也缺少直接例子。本轮沿用中英文既有 URL，补齐七档概览、四类共 31 项声音、名称/数值/原始单位/类别组合筛选、空结果与重置、40–70 分贝参考、对数刻度及 NIOSH 职业暴露参考。

概览采用七档独立整行背景色，声音列表采用对齐与分隔线，来源与条件就近显示；后续解释保持连续阅读。手机导航将品牌/外观/语言与菜单分成两行，保留开始测量、分贝对照表、声音知识、本机记录。目录使用短标签，避免完整章节标题占去过多首屏空间；来源锚点增加定位间距，避免被固定导航遮住。

## 修改职责

- `src/lib/content/sound-references.ts`：声音名称、类别、来源单位、范围、比较条件、七档示例和来源注册。
- `src/lib/content/decibel-chart.ts`：中英文文章、目录短标签、解释、暴露参考与关联内容；`articles.ts` 引用该模块。
- `src/features/decibel-chart/`：服务端概览和局部客户端查询。客户端只接收当前语言、数值、名称搜索别名与来源锚点，不包含整篇双语正文。
- `src/components/content-page/`：章节插槽、短目录和来源锚点；`route-page` 接入现有对照页。
- `src/components/site-document/`：一级菜单、手机布局和知识父栏目排除独立对照入口，确保只选中一个栏目。
- `scripts/check-content.ts`、`scripts/check-export.ts`：数据关系、完整静态条目、来源锚点、中英主导航与唯一选中状态检查。
- 产品说明、关键词映射、设计记录、AGENTS.md 和文档索引同步本地实现状态，维持 22 个页面、20 个可索引 URL。

没有修改包清单或锁文件，没有新增依赖。组件样式留在相邻 CSS Modules；字体沿用固定语义变量。单文件有效行数均未超过 700，单函数未超过 300。

## 来源与口径核对

本节记录 2026-10-18 的核对范围。当前 31 项的官方原文、NIH 九项替换及条件修正，以 [2026-10-20 逐项核验](./声音参考来源逐项核验.md) 为准。

声音数值按来源保留 dB 或 dBA，不自行补充频率计权和未说明的测距，不将同名声源压成一个通用保证值。

- [WHO：Safe listening](https://www.who.int/news-room/questions-and-answers/item/deafness-and-hearing-loss-safe-listening)：呼吸、耳语、图书馆、门铃、车内交通、吹风机、5 米汽车喇叭、风镐和飞机起飞示例。
- [NIH 教育资料 Table 2](https://www.ncbi.nlm.nih.gov/books/NBK20366/)：家庭、干衣机、洗衣机、吸尘器、餐厅、道路交通、剃须刀、电钻及链锯。通过官方页面搜索索引的完整表格文本核对；本轮直连触发浏览器校验，未绕过校验。
- [NIDCD：Noise-Induced Hearing Loss](https://www.nidcd.nih.gov/health/noise-induced-hearing-loss)：交谈、摩托车、电影院、赛事、耳机、警笛、烟花等范围及原始 dBA。
- [CDC：Listen Up](https://www.cdc.gov/nceh/hearing_loss/infographic/index.html)：冰箱、洗碗机、音乐会与夜店示例。
- [NPS：Understanding Sound](https://www.nps.gov/subjects/sound/understandingsound.htm)：树叶、雷声和喷气机的具体环境示例，保留原条件。
- [NIOSH 职业参考](https://www.cdc.gov/niosh/noise/about/noise.html)：85 dBA / 8 小时及每增加 3 dBA 时长减半。页面明确这是职业参考，未用本站估算生成个人安全倒计时。
- [CCOHS：Noise — Basic Information](https://www.ccohs.ca/oshanswers/phys_agents/noise/noise_basic.html)：对数刻度、声能变化与同声级叠加的说明。

来源于 2026-10-18 核对，不将竞品作为声学数值或健康结论的依据。本站通用估算模型、A 计权能力与参考校准边界沿用已有说明。

## 浏览器验证

使用 Codex 内置浏览器检查本地静态预览 `http://127.0.0.1:3100/`。工具未提供可核实的浏览器引擎版本。视口范围按页面实际 CSS 宽高记录，不能用请求的面板尺寸代替实际测量。

- 中文：一级导航从首页进入对照页；仅对照入口选中；手机保留四个主要入口。
- 查询：`冰箱` 得到 1 项；`60` 得到洗碗机、干衣机、正常交谈三项；叠加家电类别得到两项；全角 `６０ dBA` 只匹配正常交谈。
- 恢复：无匹配结果显示 0 项和重置按钮；重置恢复 31 项和全部类别。清空、重置后焦点回到搜索输入。
- 来源：条目链接跳转到对应来源锚点；修正后在 288px 窄屏再次检查，来源顶部约 190px，固定导航底部约 132px，内容不再被遮挡。
- 语言与主题：对照页中英文互相对应；主题切换和页面导航保持一致。英文同样有 31 项参考和筛选。
- 布局：桌面与手机实际视口检查，无页面横向溢出；手机结果重排为名称/读数在上、条件/来源在下。说明表格在自身区域允许横向查看。

代表性实际 CSS 视口包括中文 1422×1000 桌面、749×1025 中等宽度、390×844 手机，以及英文 1155×740 桌面、320×740 手机；另检查了 288px 窄屏。各次均用实际宽度与 `documentElement.scrollWidth` 比较，无页面横向溢出。最终复核阶段未捕获浏览器 warn/error。

## 技能与边界

应用 `vercel-react-best-practices` 的服务端/客户端职责、传输字段和派生状态规则；应用 `documentation-update` 同步相关文档；按 `simplify` 复核职责与重复派生字段。BrowserAct CLI 不可用，浏览器检查使用已有内置浏览器，没有安装工具或依赖。

本轮未验证真实移动设备、生产域名、服务器响应头、线上抓取与搜索排名，也未进行声学精度或健康评估验证。只调整对照内容与导航；工作区其他并行仪表、设计与竞品文档改动保留，未回退或纳入本轮改动说明。后续上线仍需单独验证生产环境。

## 分段背景色调整（2026-10-18）

按反馈将原先四种细边框编码改为七档独立整行背景色：绿、青、蓝、黄、橙、红、玫红。移除左侧色线、概览上下边界与行分隔线，保留数值、单位、等级文字和声音示例；行间留 8px 间距，手机示例与数值左侧对齐。

修改 `src/features/decibel-chart/index.module.css` 的组件专属背景/文字变量及手机内边距，将 `sound-references.ts` 中首档、70–85、100–120 三档区分为 `faint`、`raised`、`intense`，同步设计规格。按 `simplify` 复核后，维持现有组件职责与静态渲染方式。

实际浏览器读取全部七档及其子元素的计算样式：亮暗主题各有七种不同背景，侧边线与行边框均为 `0px`；所有文字对背景的对比度不低于 4.5:1，亮色最低 6.73:1，暗色最低 10.48:1。[计算样式与对比度记录](../../design/decibel-chart-v1/band-color-validation.json)。

验证英文桌面亮暗主题、中文 390×844 亮色和英文 320×740 暗色手机视口。页面宽度与视口一致，七档内容无横向裁切，数值字号保持固定 20px。截图：[桌面亮色](../../design/decibel-chart-v1/bands-desktop-light.jpg)、[桌面暗色](../../design/decibel-chart-v1/bands-desktop-dark.jpg)、[中文手机亮色](../../design/decibel-chart-v1/bands-mobile-light-zh.jpg)、[英文手机暗色](../../design/decibel-chart-v1/bands-mobile-dark-en.jpg)。
