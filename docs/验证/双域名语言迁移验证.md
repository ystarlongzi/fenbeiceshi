# 双域名语言迁移验证

更新：2026-10-25。本轮继续使用同一产品、界面与测量能力，按语言拆分站点，不新增语言或批量内容。

## 页面与语言

| 站点             | 语言和路径                 | 页面数 | sitemap |
| ---------------- | -------------------------- | ------ | ------- |
| fenbeiceshi.com  | 简体根路径、繁体 `/zh-tw/` | 94     | 92      |
| soundmetergo.com | 英文根路径，不带 `/en/`    | 47     | 46      |

合计 141 个 URL、138 个可索引页面；三个本机记录页仍 noindex。两域每页自 canonical，三语同主题互相返回 hreflang，x-default 指向英文页；导航、正文、面包屑、JSON-LD、品牌和报告域名均随目标站生成。英文品牌为 SoundMeterGo。

旧英文 47 个主题（含记录页）由页面注册表派生 Nginx map，分别覆盖带／不带尾斜杠的 94 个精确地址；旧 HTTP、www 和 HTTPS 都直接 301 到英文域同主题，保留查询。未知旧路径保持 404，不统一跳首页，也不在中文包中继续发布英文 HTML。

## 工程与数据边界

- `scripts/build-sites.mjs` 顺序构建英文和中文：英文输出 `out-soundmetergo/`，剔除框架额外生成的繁体目录；中文输出 `out/`。每份输出均有 `_site.txt`，打包及服务器按域名核对，拒绝错发。
- 两域共享主题注册和静态正文；域名配置在 `src/lib/routing/sites.ts`，Nginx 迁移映射从同一注册表生成。未新增依赖，未迁移样式或重构测量引擎。
- 自动语言选择只在中文域匹配简繁，英文域保持 URL 语言；手动跨域切换进入同主题，保留主题、查询、锚点，通过 language 参数在目标域保存选择。存储失败仍有明确提示。
- localStorage、IndexedDB、麦克风授权按浏览器来源隔离。旧报告与录音留在 fenbeiceshi.com，英文记录页提供取回入口，不自动复制、重新解释或清空数据；新域首次测量须重新授权。
- 两域发布目录、Nginx 配置、日志、证书、ACME 与 DNS 凭据分开，目录白名单和路径深度防护保留。发布先英文与健康检查，再安装中文 301 并发布中文；共用 Actions 生产并发组，回滚可选站点。
