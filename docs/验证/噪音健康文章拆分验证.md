# 噪音健康文章拆分验证

日期：2026-10-20。当前为本地静态实现，未部署生产。设计依据见 [健康文章 V1](../../design/noise-health-v1/design-spec.json)。

## 页面分工与阅读顺序

新增 `/knowledge/noise-and-health/` 与英文对应页面。文章围绕“理解影响，再选择行动”重写，采用四个主章节：

1. **影响概览**：以强声与听力、日常干扰、长期研究三个开放小节，串联原有听力、睡眠、烦扰、心血管、专注与儿童主题。来源就近展示，保留研究语境。
2. **理解暴露**：先说明强度与持续时间、时段与活动、单位与平均周期。NIOSH 职业参考为默认关闭的可选阅读，不与普通家庭环境共用阈值。
3. **减少干扰**：三步顺序列表，依次处理可控声源、调整活动环境、记录观察条件。
4. **下一步**：区分听力检查、持续干扰与职业或声学评估；页尾主操作返回声音对照。

主标题收短为“噪音对健康的影响”／“Noise and health”，范围由摘要、章节与描述展开。正文开放排版，沿用固定字号与主题变量；未将原六个展开条目直接搬成六张卡片。

对照页的主目录只保留分段概览、声音查询、读数说明；健康为读数说明之后的辅助导读，仅一段文字与一个文章入口。31 项声音与原有组合筛选保持完整，职业演示和健康专属来源迁入新文章。中文桌面实测导读约 113px 高，旧 `#health` 与 `#exposure` 均可到达该入口。

首页的健康入口直达文章，普通文章列表避免重复增加同一入口；知识目录增加健康分组。原未发布的 `noise-exposure` 候选在关键词规划中合并为本次更完整的 `noise-health` 主题，未生成重复页面或缺失语言占位。

## 一手来源与适用语境复核

2026-10-20 查阅以下官方原文，并分别核对中文与英文表述：

| 来源                                                                                                        | 本文使用范围与限制                                                                    |
| ----------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| [NIH/NIDCD：Noise-Induced Hearing Loss](https://www.nidcd.nih.gov/health/noise-induced-hearing-loss)        | 强声、反复暴露、耳鸣与听力检查的一般信息；不以网页读数诊断听力变化                    |
| [CDC/NIOSH：Noise-Induced Hearing Loss](https://www.cdc.gov/niosh/noise/about/noise.html)                   | 职业 85 dBA／8 小时及每增加 3 dBA 参考时长减半；不是卧室目标或个人安全倒计时          |
| [WHO：环境噪音指导汇编](https://www.who.int/tools/compendium-on-health-and-environment/environmental-noise) | 环境噪音、烦扰及长期健康影响；不推算个人患病概率                                      |
| [WHO Europe：噪音主题概览](https://www.who.int/europe/health-topics/noise)                                  | 睡眠、日常活动、专注与环境暴露背景                                                    |
| [WHO Europe：2011 噪音资料](https://www.who.int/europe/news-room/fact-sheets/item/noise)                    | 睡眠、儿童及敏感人群语境；页面来源明确标注 2011，不将夜间全年平均指标写成瞬时读数界线 |
| [WHO Europe：2018 环境噪音指南](https://www.who.int/europe/publications/i/item/9789289053563)               | 环境声源与公共卫生指导范围，区别于职业保护参考                                        |

文章是官方公开资料的一般科普整理，不声称医学专家审校。没有新增个体诊断、量化风险预测、法规阈值或网页声学准确度承诺。规划中相应明确了该范围；临床与法规扩展仍需相应专业复核。

## 实现与文件职责

- `src/lib/content/noise-health.ts`：双语文章、三个影响小节、暴露条件、行动步骤与来源。
- `src/features/noise-health/`：服务端文章展示与相邻 CSS Modules；职业参考组件和既有公式测试随职责迁入，计算逻辑不变。
- `src/components/disclosure-anchors/`：原生展开的片段兼容处理已有对照页与文章两个使用处，提取共享；不把正文转为客户端组件。
- `src/components/content-page/`：增加可选页尾操作，健康文章回到对照；其他文章沿用既有默认操作。
- `src/features/decibel-chart/`：四项说明与简短导读；删除旧健康列表，移除职业控件，减少来源列表。
- `src/components/home-page/`、`knowledge-page/`、`route-page/` 及 `src/lib/content/articles.ts`：处理文章发现、分组与注册。canonical、hreflang、sitemap 和导航沿用现有派生方式。
- `scripts/check-content.ts` 与 `check-export.ts`：校验新双语正文、完整静态输出、来源、按需职业参考、对照页只保留一段导读及新增路由关系。
- 同步 `AGENTS.md`、SEO 规划、关键词映射、文档索引和设计规格；历史验证记录保留原日期与历史范围。

应用了 React 最佳实践、现有页面审视、文档维护与 simplify 复核。正文继续静态输出，交互只在目录、原生展开兼容与职业演示；无新增依赖、全局样式修改或无关目录迁移。涉及文件与函数均未接近 700／300 有效行阈值，用户原有 `.idea/` 未修改。
