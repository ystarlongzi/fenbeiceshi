# 分贝详情层级与内容结构验证

日期：2026-10-22。范围：既有 28 个分贝详情主题的三语正文与统一模板，本地实现，未部署。

## 依据与判断

实际浏览用户指定的 [竞品 10 分贝页](https://www.decibelmeter.org/zh/comparison/10-db)，其阅读顺序为量级结论、声音例子、相对试听、等级对比、听力提示、问答、测量及其他等级。本站旧版先讲来源与限制，五段正文的表现相近；手机目录还先于核心答案。

本轮采用“先建立直观印象，再对照、判断和行动”的顺序，保留本站字体、固定字号、七档命名与亮暗主题。10 分贝继续使用已核验的正常呼吸参考；没有把竞品的树叶例子或其他数值移植为本站来源。

## 当前结构与实现

- 首屏：短 H1、参考声级、原始单位、七档位置与每个主题单独编写的直观结论。跨档范围完整显示，手机先显示结论，再显示目录。
- 常见声音：主题表面组织原始例子、条件及出处；保留每个例子的完整单位与范围。
- 量级对比：本页和相关声音使用两列表格并排，当前例子标明“本页”；相关场景链接至真实详情，各行来源可定位。不把不同单位、测距或时间指标换算成响度倍数。
- 听力与行动：根据场景给阅读提示，说明声级、时长与反复出现的关系，链接健康影响和职业暴露时长参考。
- 观察方法：三项独立要点用编号组织，避免和连续正文混成一段。
- 常见问题：主题专属问题、参考解释和网页读数问题各有三级标题及答案；原 `browser` 锚点保留在第三问。
- 来源与延伸阅读：继续静态输出完整引用及有效链接。

`ContentPage` 只增加可选的标题、概览和章节 className 接口，已有页面继续使用原默认布局。详情的正文、表格、问答、来源及链接均为服务端静态输出；目录沿用现有组件。样式全部留在 `src/features/decibel-details/index.module.css`，未新增依赖或修改全局字号。

## 内容来源

本轮重新读取 [NIDCD](https://www.nidcd.nih.gov/health/noise-induced-hearing-loss)、[NIOSH](https://www.cdc.gov/niosh/noise/about/noise.html) 和 [CCOHS](https://www.ccohs.ca/oshanswers/phys_agents/noise/noise_basic.html) 的官方内容。听力提示依据声级、持续和重复暴露的条件，不承诺个人安全时长。原有 31 项声音数字、范围与单位未变；对比表复用同一参考对象，不从范围取中点。

## 验证结果

- `rtk npm run check` 通过：格式、ESLint（零警告）、TypeScript、130 项测试、内容检查、构建及静态产物检查全部成功；产物包含 126 个页面、123 个 sitemap URL，5,244 条内部链接及锚点有效。
- 新增回归覆盖对比行使用原始参考对象、范围与单位不变、来源完整、五节阅读顺序、三问三答与旧 `browser` 锚点。导出检查逐页确认概览先于目录，场景、对比行及问答都存在于构建 HTML。
- Chrome 实际渲染检查：简体 10 分贝桌面 1440×1000、手机 390×844；英文 47–72 分贝 320×812；繁体 100 分贝 390×844；简体 140–160 分贝 390×844。以上页面无横向溢出，H1 保持 32px，正文保持 16px；手机概览先于目录。
- 100 分贝页在概览保留 `dB / dBA`，吹风机、雷声在场景和对比行中分别保留原始单位；47–72 与 140–160 的范围没有被截断或取中点。暗色主题检查包含 100 分贝的两种单位和当前行标记。
- 实际点击对比表的树叶声进入 20 分贝详情；点击 NPS 来源定位引用；目录点击及 Enter 定位常见问题成功，三项答案直接展开。回看使用指南确认共享 `ContentPage` 的原有结论与目录布局仍正常。
- 已按 `simplify` 复核职责与复用：展示在详情功能目录，内容按场景拆分，沿用声音、档位、来源、路由及目录；本轮涉及文件均未超过 700 行有效代码，单个函数未超过 300 行。`rtk git diff --check` 通过。
