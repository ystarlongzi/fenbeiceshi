## 来源与验证边界

本轮不改变既有 31 项声级数据。复核官方网页及可读取 PDF，并沿用 [逐项来源核验](./声音参考来源逐项核验.md) 的原始数字、单位和条件；EPA 原文链接本次抓取不可达，未声称重新读取成功。历史家电表格、教学图示、测距、瞬时声音和职业参考的适用范围在相应正文中说明。

没有验证生产部署、搜索引擎收录与排名、真实手机、Safari 或实际读屏设备。网页观察不提供声学精度或个人安全时长结论。

## 展开说明不再展示来源（2026-10-22）

31 项声音展开后只保留比较条件和一个「了解 ×× 分贝」行内链接，不再显示来源机构、资料年份、表格出处或来源箭头入口。14 项原说明含有出处的声音新增显式三语 `description`，其余声音复用原有简短条件；测距、运行状态、完整范围和单位保持原口径。原始 `context` 和 `source` 保留在详情页，没有改写来源数据或数值。

`SoundReferenceList` 删除来源入口，客户端 Props 与搜索类型移除不再使用的来源字段，简化只剩一个正文链接的样式。更新搜索提示、页面摘要、关键词归属及设计规格。原对照页底部的统一来源章节继续保留；本轮调整范围为声音条目的展开说明。

实际验证：

- `rtk npm run check` 全部通过，含格式、零警告 lint、类型、128 项测试、内容检查、构建与静态导出；126 个页面、123 个 sitemap URL、4563 条站内链接与锚点。
- 扩展导出校验覆盖三语 93 条声音说明：说明正文只含一个对应数值详情链接，且没有来源机构名；完整详情仍静态输出原始条件、来源及引用链接。
- Chrome 简体桌面 1440 × 1000：七档初始折叠，搜索洗衣机展开后仅有 0.9 米与运行条件、47–72 详情入口；实际点击后，详情仍显示 1986 年、Table 2、0.9 米及 NIOSH 引用。
