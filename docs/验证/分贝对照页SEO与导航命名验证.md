# 分贝对照页 SEO 与导航命名验证

日期：2026-11-23。范围：发布前的本地 Web 验收记录，生产发布结果另行记录。

## 任务与内容关系

本轮依据 [Bing 中文页面 SEO 优化优先级](../产品/Bing中文页面SEO优化优先级.md) 的实际查询与收录基线，先优化已有简繁分贝对照页，不增加 URL。中文主导航使用「分贝对照／分貝對照」，更直接对应查询声音量级的任务；页面搜索标题与 H1 继续使用「分贝对照表」。英文及其他国际语言保留原导航译名。

原手机页面先出现目录，再出现简短答案；四个声音详情入口需要展开分组和具体声音。现将中文简短答案放在目录前，直接链接 30 dB、40 dB、45–55 dB、60–70 dBA 的现有详情。七档声音查询继续作为正文主体，原声音单位、范围、条件及来源保持完整。声音列表之后增加中国大陆噪音法规入口，明确判断还需结合声源、时段与测量条件；不将参考声音当作法定限值。

## 实现与检查入口

- `src/lib/content/decibel-chart.ts` 维护简繁导读片段及法规入口文案，普通文字摘要由相同片段生成；页面更新日期同步为本轮维护日期。
- `src/features/decibel-chart/` 复用服务端 `ContentPage.overview`，静态输出导读及原生链接；使用相邻 CSS Modules、固定 16px 正文和主题变量，不增加客户端状态或依赖。
- `src/components/site-document/index.tsx` 同步桌面与手机的中文导航名称；导航数量、顺序、URL 和选中归属沿用现有实现。
- `scripts/export-checks/chart-overview.ts` 检查静态答案、四个详情入口及原单位、目录前位置、法规链接语言和位置；现有导出检查继续验证各页导航、七档折叠与全部声音内容。
- 同步导航规格、分贝对照 SEO 补充规格、整站规划、关键词映射、项目约定及文档索引。数值查询仍归已有详情页，法规查询归现有法规页。

## 自动化验证

`npm run check` 通过：Prettier、零警告 ESLint、TypeScript strict、183 项应用测试、31 项部署脚本测试、24 种新增语言各 1431 条词典校验、44 个正文主题的 27 语校验、双站生产构建及全部静态产物检查。部署测试中的 4 项真实 Linux／Nginx／TLS 演练按本地配置跳过，没有执行生产发布。完整输出保存在 `artifacts/chart-seo-20261123/check.log`。

静态检查覆盖中文 94 页、英文基础 47 页及新增语言 1128 页，共 1269 个 URL；中文与国际站 sitemap 分别为 92 和 1150 项。新增导读的四个原生链接、目录前位置、法规入口及简繁路径均通过断言，原有声音内容、导航选中规则、canonical、hreflang 和结构化数据继续通过检查。

`git diff --check` 通过；本轮涉及的文档共 189 条本地链接有效，3 份设计／关键词 JSON 可解析。npm 仍输出既有的 `Unknown user/env config "home"` 提示，不影响检查结果。

## 实际浏览器验证

通过 `npm run preview` 与 `NEXT_PUBLIC_SITE_TARGET=soundmetergo npm run preview` 在本地静态产物中验证，使用 Codex 内置 Chromium：

- 1280×720 简体桌面：导航为「分贝对照」，当前页选中正确；导读为 16px，四个详情入口可见，七档默认折叠。见 [桌面截图](../../design/decibel-chart-seo-v1/after-desktop.jpg)。
- 375×812 简体手机：导读底部约 424px，目录顶部约 480px，先读答案再进入目录；文档宽度为 375px，未出现页面横向溢出。见 [手机截图](../../design/decibel-chart-seo-v1/after-mobile.jpg)。
- 搜索「冰箱」只显示 1 项参考并展开匹配分组；清空后恢复 31 项且七档均折叠。Enter 可展开和收起安静分组。
- 简体手机菜单显示四项导航，点击「分贝对照」后关闭菜单，恢复背景滚动并将焦点返回菜单按钮。实际打开 40 分贝详情及中国大陆噪音法规页，核对 URL 和 H1；法规链接在手机换行后仍可点击。
- 320×740 简体深色：导读保持 16px，数值与原单位同行，文档宽度为 320px；答案仍在目录前。见 [深色窄屏截图](../../design/decibel-chart-seo-v1/chinese-dark-320.jpg)。
- 320×740 繁体深色：显示独立繁体导读，四个详情链接及法规链接均带 `/zh-tw/`；菜单使用「分貝對照」。Enter 实际进入 60–70 分贝繁体详情，核对 URL 和 H1。1280×720 繁体桌面导航、导读及目录位置也已核对。见 [繁体手机截图](../../design/decibel-chart-seo-v1/traditional-mobile.jpg)。
- 1280×720 英文：保留 Decibel guide、原英文摘要和页面层级，没有新增中文导读或法规段落。见 [英文回归截图](../../design/decibel-chart-seo-v1/english-desktop.jpg)。
- 验证后恢复本地主题为「跟随系统」，清除临时视口覆盖。简体页面控制台未发现错误。

按 React 性能规范和 simplify 复核后，继续复用现有服务端正文、路由与页面入口；简繁摘要从同一份导读片段生成，未增加客户端状态、共享抽象或第三方依赖。新增及修改的内容、页面和检查模块均在项目规模限制内；现有大型导出检查仅增加调用，新增断言独立维护。

## 验证边界

本轮不涉及测量模型、麦克风或录音行为、声音来源数据、健康参考表及法定限值更新。浏览器手机检查为视口模拟；真实设备及其他浏览器内核未覆盖。本文未覆盖生产运行，也没有上线后的 Bing 抓取、点击率或排名变化数据。
