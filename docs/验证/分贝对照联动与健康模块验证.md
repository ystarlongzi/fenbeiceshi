# 分贝对照联动与健康模块验证

验证日期：2026-10-18。本轮落实 [竞品分析第九节](../产品/竞品分析与设计决策.md) 中的交互与健康内容建议；实现依据见 [分贝对照 V2 规格](../../design/decibel-chart-v2/design-spec.json)。

## 实现范围

- 中英文对照页的七档整行色带、0–160 整数输入和滑块共享选择状态，声音名称、来源单位与类别可组合筛选；默认完整显示 31 项参考。交界单值归入后一档，跨档示例按范围交集匹配，末档包含 160。
- 点击分段后聚焦并滚动到结果数量；单值输入及滑块操作保持当前操作焦点。支持只清除分贝条件与重置全部筛选。非法数值明确提示并暂不显示匹配结果，避免沿用旧结果。
- 独立的 85–100 整数 dBA 职业暴露关系演示采用 NIOSH 的 85 dBA／8 小时及每增加 3 dBA 时长减半的关系。演示不读取仪表估算，空值、越界和小数没有时长结果。
- 增加听力、睡眠、烦扰与压力、长期心血管影响、专注与学习、儿童学习环境六个主题。摘要、背景、行动和来源均存在于构建 HTML；原生 details 支持鼠标与键盘展开。
- 首页声音知识区增加简短健康导读，分别链接到本语言现有对照页的 `#health`。文章目录纳入健康模块，沿用滚动高亮。

## 文件职责与设计复核

- `src/features/decibel-chart/sound-explorer/` 管理局部选择上下文、数值控件及输入校验；`sound-overview/` 管理色带，原有 `sound-reference-list/` 负责名称、类别与结果。
- `exposure-explorer/` 独立管理职业关系计算；`health-effects/` 为服务端展示组件；双语内容与来源集中在 `src/lib/content/health-effects.ts`。
- 服务端文章通过 children 进入局部 Client Provider，只传入本语言需要的七档展示数据；健康正文无需客户端状态。未新增依赖或路由。
- 色带复用 V1 七档亮暗底色；单值说明跟随对应底色。健康主题作为同级对象双列排列，手机单列；背景与行动按需展开，来源保持可见。相邻 CSS Modules 管理样式，保留现有固定字号与主题变量。
- 应用了 React 性能、组合模式、simplify 与文档维护技能。复核了派生状态、上下文边界、组件职责及修改范围；未进行无关目录迁移。

## 内容来源与适用范围

2026-10-18 核对一手资料：

- [CDC/NIOSH 职业噪音资料](https://www.cdc.gov/niosh/noise/about/noise.html)：职业 85 dBA／8 小时、3 dBA 交换率及听力风险；页面保留职业适用范围。
- [WHO 环境噪音指导汇编](https://www.who.int/tools/compendium-on-health-and-environment/environmental-noise)：长期环境噪音、睡眠及部分心血管影响；不据此计算个人患病概率。
- [WHO Europe 噪音资料](https://www.who.int/europe/news-room/fact-sheets/item/noise)：夜间噪音指标的室内外及平均周期语境、儿童长期飞机噪音研究。未把卧室外全年夜间平均值写成室内瞬时界线。
- [WHO Europe 机制资料](https://www.who.int/europe/publications/i/item/WHO-EURO-2018-3009-42767-59666)：环境噪音、压力途径、感知和心理因素。
- [WHO Europe 噪音主题概览](https://www.who.int/europe/health-topics/noise)：工作与学习表现的影响。

内容为公开资料的一般科普，未声称医学专家审校；独立健康文章仍按原规划保持草稿。网页查询保留原来源 dB / dBA，不作单位换算；职业演示不接入未经校准的通用估算读数。
