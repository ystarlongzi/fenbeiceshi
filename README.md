# 分贝测试 · fenbeiceshi.com

Web 优先、适配手机的浏览器声音观察工具。支持简体中文、繁体中文和英文，包括三种仪表、全屏、声音趋势、参考校准、本机摘要记录和基础知识。

默认显示未校准的通用估算噪音分贝，仪表、色带、趋势、统计与新记录共用口径；麦克风旁用小信号柱反馈输入。参考校准可选，相关计算、模型参数与旧记录兼容见 [噪音估算口径](./docs/产品/噪音估算口径.md)。当前通用偏移为 +100，是未经跨设备声学精度验证的粗略估算假设。它不是认证声级计，不输出 dBA、环境安全或合规结论。同步录音默认关闭；开启后随真实测量录制，结束后可播放、下载 MP3 或原始 PCM，音频仅暂存当前页面、不上传。刷新、离开页面或新录音会清除，需及时下载；摘要不含音频。单次最多 10 分钟或 64 MiB 采样，达到上限停止录音但测量继续，见 [同步录音说明](./docs/产品/同步录音说明.md)。

简体中文位于 `/`，繁体中文位于 `/zh-tw/`，英文位于 `/en/`。页头或手机菜单的语言下拉框显示完整名称，可切换到当前页面的对应语言；三种语言共用当前浏览器中的测量记录。文案在构建时输出，不依赖浏览器自动翻译。维护与验证见 [繁体中文支持验证](./docs/验证/繁体中文支持验证.md)。

## 本地运行

Node `>=24.11.0 <27`，npm 和项目锁文件。

```sh
npm ci
npm run dev -- --port 3100
```

打开 [本地预览](http://127.0.0.1:3100)。点击开始才请求麦克风；无需权限也可使用带明确标记的演示。演示不能保存或导出为测量记录。

## 检查与静态导出

```sh
npm run check
```

依次运行格式、ESLint、strict 类型、测试、内容检查、构建和静态产物检查。产物为 `out/`，可通过本机静态预览验证：

```sh
npm run preview
```

不要同时在同一端口运行 dev 与 preview。静态预览默认监听 `127.0.0.1:3100`，可用 `FENBEI_PREVIEW_PORT` 指定其他端口。它不是生产服务器。

当前生成 39 个可索引的三语 URL；另有三个 noindex 本机记录功能页。正文在构建时生成，新增内容后需重新构建。GitHub Actions 使用同一个 check 入口，`out/` 仅在当前 runner 完成校验，不上传 GitHub Artifacts；npm 缓存只用于依赖。后续生产发布采用同一 job 构建后直接 SSH 传输，回滚版本保留在服务器，具体边界见 [工程与部署参考](./docs/开发/工程与部署参考.md)。本机既有 Git hooks 配置不由初始化自动覆盖。
